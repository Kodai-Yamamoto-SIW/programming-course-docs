# リンクのマークアップ（a要素）

## Type

cloze

## Prompt

以下の条件にしたがって、リンクを表すHTML要素を記述せよ。

- リンク先のURL：`https://google.com`
- 表示するリンクテキスト：`Googleで検索`
- リンクは**新しいタブ**で開くようにすること

```html
{{<a href="https://google.com" target="_blank">Googleで検索</a>}}
```

### Exam

外部リンクの記述が出題されますが、リンク先のURLや、表示するリンクテキストが変わります。
URLやリンクテキストが変わっても、正しくa要素をマークアップできるようにしておく必要があります。

## Explanation

### 解答・解説

```html
<a href="https://google.com" target="_blank">Googleで検索</a>
```

**`a`タグの構成要素：**

1. **`href`属性** ：リンク先のURLを指定する。
2. **`target="_blank"`属性** ：新しいタブで開くために指定する。
3. **リンクテキスト** ：クリックできる文字（タグの中身）。

**各属性の詳細：**

- **`href`属性** ：
  - 外部サイト：`href="https://example.com"`
  - 同じサイト内：`href="about.html"`
  - ページ内リンク：`href="#section1"`
- **`target`属性** ：
  - `target="_blank"` ：新しいタブで開く
