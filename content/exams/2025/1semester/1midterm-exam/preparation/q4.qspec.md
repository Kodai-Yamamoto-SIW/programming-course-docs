# CSSの役割とHTMLとの関係

## Type

descriptive

## Prompt

以下の2つの言語がWebサイト制作において、どのような役割を担っているか簡潔に答えよ。

1. HTMLの役割
2. CSSの役割

### Exam

HTMLとCSSの役割分担を正しく理解しているか問われます。
「文書の構造を作るのはどちらか」「見た目を整えるのはどちらか」といった形式で出題されます。

## Explanation

### 解答・解説

**役割の違い：**

1. **HTML** ：文書の**構造**を作る（骨組み）。
2. **CSS** ：文書の**見た目・装飾**を整える（肉付け）。

**例え話：**

- HTML = 建物の「骨組み・壁・ドア」
- CSS = 建物の「壁紙・外装の色・インテリア」

Webサイトを制作するときは、まずHTMLで文章の構造（見出しや段落など）を作り、その後にCSSでデザイン（色や配置など）を整えていきます。
