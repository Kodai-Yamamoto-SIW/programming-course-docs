# HTMLの基本構造

## Type

cloze

## Prompt

以下のHTMLのコードには文法上の誤りがあります。正しい文法となるように修正しなさい。

```html
<!DOCTYPE html>
<html>
  <head>
    <title>ページのタイトル</title>
    <body>
      <h1>こんにちは</h1>
    </body>
  </head>
</html>
```

### Exam

修正問題ではなく、選択式で文法上の誤りのないHTMLを選ぶ形式で出題されます。
4つの選択肢から正しいHTMLの基本構造を選ぶ問題になります。

## Explanation

### 解答

**間違い：**
`<body>` タグが `<head>` タグの中に入っている

**正しいHTML構造：**

```html
<!DOCTYPE html>
<html>
  <head>
    <title>ページのタイトル</title>
  </head>
  <body>
    <h1>こんにちは</h1>
  </body>
</html>
```

### 解説

**HTMLの基本構造の覚え方：**

1. `<!DOCTYPE html>` ：HTMLであることを宣言
2. `<html>` ：HTMLドキュメント全体を囲む
3. `<head>` ：情報の管理（タイトル、CSS、メタデータなど）
4. `<body>` ：ページに表示される内容

**入れ子の順番：**

```text
html
 |-- head
 |   |-- title
 |   `-- その他のメタデータ
 `-- body
     `-- 表示される内容
```

**よくある間違い：**

- `<body>` を `<head>` の中に書く
- `<!DOCTYPE html>` を忘れる
- 閉じタグを忘れる
