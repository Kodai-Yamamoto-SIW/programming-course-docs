# タグの意味（テキスト関連）

## Type

descriptive

## Prompt

以下のタグがそれぞれどのような意味・目的で使われるか、簡潔に一言で答えよ。

- `br`
- `h1`
- `strong`
- `p`
- `small`

### Exam

タグの意味を説明する問題ではなく、選択式で「〜を表すHTMLタグを選べ」という形式で出題されます。
複数の選択肢からタグを選ぶ問題になります。

## Explanation

### 解答・解説

**各タグの意味：**

- **`<br>`** ：**改行**を表す。

```html
<p>1行目<br />2行目</p>
```

- **`<h1>`** ：**見出し**（最も重要な見出し）。

```html
<h1>メインタイトル</h1>
<h2>サブタイトル</h2>
```

- **`<strong>`** ：**重要**なテキストの強調。

```html
<p>この商品は<strong>送料無料</strong>です。</p>
```

- **`<p>`** ：**段落**（文章のまとまり）。

```html
<p>これは1つ目の段落です。</p>
<p>これは2つ目の段落です。</p>
```

- **`<small>`** ：**補足情報**（小さな文字で表示）。

```html
<p>商品価格：1000円 <small>※税込み</small></p>
```

**覚え方：**

- `h1` = Heading 1（見出し1）
- `p` = Paragraph（段落）
- `br` = Break（改行）
- `strong` = 強い（重要）
- `small` = 小さい（補足）
