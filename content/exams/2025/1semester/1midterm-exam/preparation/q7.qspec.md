# CSSの優先順位（カスケード）

## Type

descriptive

## Prompt

同じHTML要素（ここでは `h1`）に対して、以下のように複数の指定がある場合、最終的に適用される色はどれか答えよ。また、その理由も簡潔に述べよ。

```css
h1 {
  color: blue;
}
h1 {
  color: red;
}
```

### Exam

CSSの「順次性」や「優先順位」について問われます。
同じ強さのセレクタであれば「後に書かれた方が優先される」という原則を理解しているか問われます。

## Explanation

### 解答・解説

**適用される色：** `red`

**理由：**
CSSには、同じ優先度の指定がある場合、**より後に（下に）書かれた指定が優先される**というルールがあるため。

**優先順位の基本ルール：**

1. **後に書かれたものが優先**（カスケード）
2. **より詳細に指定されたものが優先**（ID > クラス > タグ）
3. **インラインCSS（style属性）が最も優先**
