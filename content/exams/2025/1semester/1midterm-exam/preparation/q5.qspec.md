# CSSの基本構文（セレクタ・プロパティ・値）

## Type

descriptive

## Prompt

以下のCSSのコードにおいて、「セレクタ」「プロパティ」「値」はそれぞれどれか答えよ。

```css
h1 {
  color: red;
}
```

### Exam

CSSの用語（セレクタ、プロパティ、値）を正しく理解しているか問われます。
選択肢の中から「セレクタはどれか」「値はどれか」などを選ぶ形式で出題されます。

## Explanation

### 解答・解説

**CSSの基本構造：**

- **セレクタ** ：`h1` （「どこに」適用するか）
- **プロパティ** ：`color` （「何を」変えるか）
- **値** ：`red` （「どのように」変えるか）

**構成のルール：**

- セレクタの後には `{ }` （波括弧）を書く
- プロパティと値の間には `:` （コロン）を置く
- 文末（値の後）には `;` （セミコロン）を置く
