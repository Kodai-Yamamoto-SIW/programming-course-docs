<Exercise>
以下の説明に該当するHTMLタグを書きなさい。

1. 文書のセクション（章や節）を表すタグ：（　　　　）
2. 最も重要な見出しを表すタグ：（　　　　）
3. 補足的な説明や小さな文字で表示される内容を表すタグ：（　　　　）
4. 段落を表すタグ：（　　　　）
5. 重要な内容を強調するタグ：（　　　　）

- `<strong>`タグは重要な内容を強調するための要素です
</Solution>

## 問題3：CSS色指定（穴埋め式）

<Exercise>
CSSの色指定方法について、以下の空欄を埋めなさい。

1. カラーネームで紫色：`color: （　　　　）;`
2. 16進数で黒色：`color: （　　　　）;`
3. RGB値で赤色：`color: （　　　　）;`
4. RGBAで不透明度0.6の青色：`color: （　　　　）;`

> [!TIP]
>
> **本試験では**
> 同じ穴埋め式で、色の種類や不透明度の値が変わります。

> [!NOTE]
>
> **採点基準・配点**
> - 各色指定方法が正しく記述されている：各2点×4問

<Solution>
### 解答
1. カラーネームで紫色：`color: purple;`
2. 16進数で黒色：`color: #000000;` または `color: #000;`
3. RGB値で赤色：`color: rgb(255, 0, 0);`
4. RGBAで不透明度0.6の青色：`color: rgba(0, 0, 255, 0.6);`

### 解説
- カラーネームは英語の色名（red, blue, green等）で指定します
- 16進数は#に続いて6桁（#ffffff）または3桁の短縮形（#fff）で指定します
- RGB値はrgb(赤, 緑, 青)の形式で、各値は0-255の範囲で指定します
- RGBAはRGBに不透明度（アルファ値）を加えたもので、不透明度は0.0（完全透明）から1.0（完全不透明）で指定します
</Solution>
</Exercise>

## 問題4：CSS適用順序（記述式）

<Exercise>
以下のCSSが書かれているとき、p要素の文字色は何色になるか答えなさい。また、その理由も簡潔に説明しなさい。

```css
p {
    color: purple;
    color: orange;
}
```

**文字色：（　　　　）**

**理由：**

> [!TIP]
>
> **本試験では**
> 選択式になり、要素の種類や色の順番が変わります。

> [!NOTE]
>
> **採点基準・配点**
> - 正答：2点

### 解答


```css

    color: purple;

}
```

1. `<nav>`内の`<h2>`：（　　　　）色
2. `<article>`内の`<h2>`：（　　　　）色
3. `<div>`内の`<h3>`：（　　　　）色
4. `<div>`内の`<p>`：（　　　　）色

>

## 問題9：単位の対応（記述式）

<Exercise>
以下の単位について説明しなさい。

1. `vh`：（　　　　）
2. `%`：（　　　　）
3. `rem`：（　　　　）
4. `px`：（　　　　）
5. `em`：（　　　　）

> [!TIP]
>
> **本試験では**
> 選択肢形式になり、単位の種類や順番が変わります。

> [!NOTE]
>
> **採点基準・配点**
> - 各単位の説明が正しく記述されている：各1点×5問

<Solution>
### 解答
1. `vh`：**ビューポート高さに対する割合**
2. `%`：**親要素に対する割合**
3. `rem`：**ルート要素のフォントサイズに対する相対値**
4. `px`：**絶対的なピクセル値**

- `%`は親要素のサイズを基準とした相対値です
- `rem`はルート要素（html）のフォントサイズを基準とした相対値です
- `px`は画面上の1ピクセルを基準とするサイズで指定します
- `em`は親要素のフォントサイズを基準とした相対値です
</Solution>
</Exercise>

## 問題10：単位計算（記述式）

<Exercise>
その親要素のフォントサイズが20pxの場合、`font-size: 1.2em;`で指定された要素のフォントサイズは何pxになるか計算過程も含めて答えなさい。

**計算過程：**

**答え：（　　　　）px**

> [!TIP]
>
> **本試験では**
> 穴埋め式になり、親要素のサイズやem値が変わります。

> [!NOTE]
>
> **採点基準・配点**
> - 正答：5点

<Solution>
### 解答
**計算過程：20px × 1.2 = 24px**

**答え：24px**

### 解説
`em`は親要素のフォントサイズに対する相対値です。  
計算式：親要素のフォントサイズ × em値 = 実際のサイズ  
20px × 1.2 = 24px

したがって、`font-size: 1.2em;`で指定された要素のフォントサイズは24pxになります。
</Solution>
</Exercise>

## 問題11：テキスト装飾知識（記述式）

<Exercise>
以下のCSSプロパティが何を設定するものか答えなさい。

1. `text-align: right;`：（　　　　）
2. `line-height: 2.0;`：（　　　　）
3. `font-size: 18px;`：（　　　　）

> [!TIP]
>
> **本試験では**
> 選択肢形式になり、プロパティや値が変わります。

> [!NOTE]
>
> **採点基準・配点**
> - 各プロパティの説明が正しい：2点×3問

<Solution>
### 解答
1. `text-align: right;`：**テキストを右揃えにする**
2. `line-height: 2.0;`：**行間を2倍に設定する**

- `line-height`は行の高さ（行間）を設定します。数値のみの場合はフォントサイズの倍数を表します
- `font-size`は文字の大きさを設定するプロパティです
</Solution>
