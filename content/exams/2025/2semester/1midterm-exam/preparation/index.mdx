## 問題1：セレクタの基本（2点）

<Exercise>
次のCSSの中で、`div` タグの中にある `p` タグ**だけ**にスタイルを適用するセレクタとして正しいものを選びなさい。

A. `p div`  
B. `div + p`  
C. `div, p`  
D. `div p`

**答え**: （　　　）

> [!TIP]
>
> **本試験では**
> タグ名を変更した問題が出題されます。

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**正解：D**

### 解説

- A `p div` は、`p` タグの中にある `div` タグにスタイルを適用します（逆です）。
- B `div + p` は隣接セレクタで、`div` タグの**直後**にある `p` タグにスタイルを適用します（`div` の中ではない）。
- C `div, p` はグループセレクタで、`div` タグと `p` タグの**両方**にスタイルを適用します（`div` の中だけではない）。
- D `div p` は**子孫セレクタ**で、`div` タグの中にある `p` タグすべてにスタイルを適用します。これが正解です。
  </Solution>
  </Exercise>

## 問題2：疑似クラス（2点）

<Exercise>
次のCSSの説明として正しいものを選びなさい。

```css
a:active {
  color: blue;
}
```

A. リンクをクリックしている間、青色になる  
B. リンクが訪問済みの場合、青色になる  
C. すべてのリンクが常に青色になる  
D. リンクにマウスカーソルを重ねたとき、青色になる

**答え**: （　　　）

> [!TIP]
>
> **本試験では**
> 疑似クラスの種類を変更した問題が出題されます（`:hover`, `:active`, `:focus` のいずれか）。

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**正解：A**

### 解説

`:active` 疑似クラスは、要素を**クリックしている間**にスタイルを適用します。リンク（`a` タグ）の場合、マウスボタンを押している間に色が変わるなどのインタラクティブな効果を実現できます。

- B は `:visited` 疑似クラスの説明です。
- C は単純に `a { color: blue; }` と書いた場合の説明です。
- D は `:hover` 疑似クラスの説明です。
  </Solution>
  </Exercise>

## 問題3：背景の繰り返しと位置（2点）

<Exercise>
次の空欄に当てはまる適切なプロパティ名を書きなさい。

```css
.box {
  (ア): no-repeat;        /* 背景画像の繰り返しを無効にする */
  (イ): center center;    /* 背景画像の表示位置を中央にする */
}
```

**(ア)**: ＿＿＿＿＿＿＿＿＿＿＿＿＿＿  
**(イ)**: ＿＿＿＿＿＿＿＿＿＿＿＿＿＿

> [!TIP]
>
> **本試験では**
> background- 系の、別のプロパティの問題が出題されます（`background-color`, `background-image`, `background-repeat`, `background-position`, `background-attachment`, `background-size` のいずれか）。

> [!NOTE]
>
> **採点基準・配点**
>
> - 1つ目のプロパティが正答：1点
> - 2つ目のプロパティが正答：1点

<Solution>
### 解答
- **(ア)**: `background-repeat`
- **(イ)**: `background-position`

### 解説

- `background-repeat` は背景画像のタイル表示（繰り返し）方法を指定します。主な値には `repeat`（両方向に繰り返し）、`no-repeat`（繰り返しなし）、`repeat-x`（水平方向のみ）、`repeat-y`（垂直方向のみ）などがあります。
- `background-position` は背景画像の基準位置を指定します。`left`/`center`/`right` と `top`/`center`/`bottom` のキーワード指定や、`50% 50%`、`10px 20px` などの数値指定が可能です。

これらは `background` 一括指定プロパティでまとめて指定することも可能ですが、この問題では個別プロパティ名を問うています。

</Solution>
</Exercise>

## 問題4：CSSアニメーション - transition（2点）

<Exercise>
次の空欄に当てはまる適切なプロパティ名を書きなさい。

```css
.button {
  color: black;
  transition: (ア) 0.5s;
}

.button:hover {
  color: white;
}
```

上記のコードは、ボタンにマウスを乗せたとき、文字色が黒から白に0.5秒かけて滑らかに変化するアニメーションを実現しています。

**(ア)**: ＿＿＿＿＿＿＿＿＿＿＿＿＿＿

> [!TIP]
>
> **本試験では**
> この滑らかにプロパティを変化させるために必要なプロパティの指定方法が出題されます。  
> （このプロパティ名、プロパティの値、時間のいずれか）

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**(ア) の正解**: `color`

### 解説

`transition` プロパティは、CSS プロパティの値の変化を滑らかにアニメーション化するプロパティです。

基本的な構文：

```css
transition: プロパティ名 時間;
```

この問題では：

- `color` がアニメーション化するプロパティ（空欄 (ア) の答え）
- `0.5s` が変化にかかる時間（0.5秒）

`:hover` 疑似クラスと組み合わせることで、マウスを乗せたときに文字色が黒から白へ、0.5秒かけて滑らかに変化します。

`transition` でアニメーション化するプロパティを指定することで、そのプロパティの値の変化が滑らかになります。この問題では `color` プロパティの変化（黒→白）をアニメーション化しています。

ボタンやリンクのホバーエフェクトでよく使われる重要なプロパティです。`transition: all 0.5s;` とすると、すべてのプロパティの変化がアニメーション化されます。

</Solution>
</Exercise>

## 問題5：一括指定プロパティ - font（2点）

<Exercise>
次のCSSの説明として正しいものを選びなさい。

```css
.text {
  font:
    italic 20px Arial,
    sans-serif;
}
```

A. 文字の太さが italic、サイズが 20px、フォントが sans-serif のみ  
B. 文字のスタイルが italic、フォントが Arial、サイズは指定されていない  
C. 文字のスタイルが 20px、サイズが italic、フォントが Arial  
D. 文字のスタイルが italic、サイズが 20px、フォントが Arial または sans-serif

**答え**: （　　　）

> [!TIP]
>
> **本試験では**
> font の値を変更した問題が出題されます。

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**正解：D**

### 解説

`font` プロパティは、テキストに関する複数のプロパティを一括で指定できます。

この問題のコード：

```css
.text {
  font:
    italic 20px Arial,
    sans-serif;
}
```

これは以下のように解釈されます：

- **font-style**: `italic`（斜体）
- **font-size**: `20px`（文字サイズ）
- **font-family**: `Arial, sans-serif`（フォントファミリー）

フォントファミリーは**カンマ区切りで複数指定**でき、最初のフォント（Arial）が使えない場合、次のフォント（sans-serif）が使われます。これを「フォールバック」と呼びます。

各選択肢の解説：

- A 誤り。`italic` は太さ（font-weight）ではなくスタイル（font-style）です。また、sans-serif だけでなく Arial も指定されています
- B 誤り。サイズ（20px）も指定されています
- C 誤り。スタイルとサイズが逆です。`italic` はスタイル、`20px` はサイズです
- D **正解**。スタイルが italic、サイズが 20px、フォントが Arial または sans-serif（フォールバック）
  </Solution>
  </Exercise>

## 問題6：装飾エフェクト - border-radius（2点）

<Exercise>
次のCSSで、要素の角がどのような形状になるかを説明しなさい。

```css
.circle {
  width: 150px;
  height: 150px;
  border-radius: 50%;
}
```

**説明**: ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

> [!TIP]
>
> **本試験では**
> 要素の `width`、`height` を変更した問題が出題されます。

> [!NOTE]
>
> **採点基準・配点**
>
> - 「円形」「円」「丸」などの表現が含まれている：1点
> - 角の形状が丸くなる、ことを推論できる表現が含まれている：1点

<Solution>
### 解答
**模範解答**: 「正方形が完全な円形になる」「円になる」など、「円」の表現を含む説明。

### 解説

`border-radius: 50%;` は、要素の角を丸くするプロパティです。`50%` を指定すると、要素の幅と高さの半分の半径で角が丸くなります。

この問題では、幅（`width`）と高さ（`height`）が両方とも `150px` の正方形なので、`border-radius: 50%;` を指定すると、**完全な円形**になります。

もし長方形に `border-radius: 50%;` を指定すると、楕円形になります。

</Solution>
</Exercise>

## 問題7：装飾エフェクト - グラデーション（2点）

<Exercise>
次の空欄に当てはまる適切な関数名を書きなさい。

```css
.circle-gradient {
  background: (ア) (circle, #ff6b6b, #4ecdc4);
}
```

**(ア)**: ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

> [!TIP]
>
> **本試験では**
> グラデーションの種類（`linear-gradient` または `radial-gradient`）、方向や色を変更した問題が出題されます。

> [!NOTE]
>
> **採点基準・配点**
>
> - `gradient` を含む：1点
> - 正答：1点

<Solution>
### 解答
**(ア) の正解**: `radial-gradient`

### 解説

`radial-gradient()` は、**円形・放射状のグラデーション**画像を作成する CSS 関数です。

書き方は以下の通りです：

```css
background: radial-gradient(形状, 開始色, 終了色);
```

中心から外側に向かって色が変化するグラデーションが作成されます。

他にも `linear-gradient()` という直線的なグラデーション画像を作る関数もあります。`linear-gradient()` は `to right`、`to bottom` などの方向を指定して、一方向に色が変化するグラデーションを作ります。

</Solution>

## 問題8：position プロパティ（2点）

<Exercise>
次の説明に当てはまる `position` の値を書きなさい。

「通常は文書の流れに従って配置されるが、スクロールして特定の位置に達すると画面に貼り付いて固定される配置方法。スクロールしても一定の位置に留まり続けるヘッダーなどでよく使われる。」

**答え**: `position: ＿＿＿＿＿＿＿＿＿＿;`

> [!TIP]
>
> **本試験では**
> position の種類を変更した問題が出題されます（`relative`, `fixed`, `sticky`, `absolute` のいずれか）。

> [!NOTE]
>
> **採点基準・配点**
>
> - `position` プロパティの値としてエラーではない値を書いている：1点
> - 正答：1点

<Solution>
### 解答
**正解**: `sticky`

### 解説

`position: sticky;` は、要素を**スクロールに応じて固定**する配置方法です。

主な特徴：

- 通常は文書の流れに従って配置される
- スクロールして指定位置に達すると、その位置に貼り付く（sticky）
- `top`、`right`、`bottom`、`left` で貼り付く位置を指定する

よく使われる例：

- スクロールしても常に見えるヘッダー
- テーブルの見出し行
- サイドバーのナビゲーション

他の `position` の値には、`relative`（相対配置）、`fixed`（画面固定）、`absolute`（絶対配置）などがあります。

</Solution>
</Exercise>

## 問題9：負のマージン（2点）

<Exercise>
次のHTMLとCSSで、`.box2` の表示位置について正しいものを選びなさい。

**HTML:**

```html
<div class="box1"></div>
<div class="box2"></div>
```

**CSS:**

```css
.box1 {
  width: 200px;
  height: 100px;
  background-color: red;
  margin-bottom: -30px;
}

.box2 {
  width: 200px;
  height: 100px;
  background-color: yellow;
}
```

A. `.box2` が `.box1` の一部と重なるように上にずれて配置される  
B. `.box2` が `.box1` の上側に配置される  
C. `.box2` が `.box1` の右側に配置される  
D. `.box2` が `.box1` から下に 30px 離れて配置される

**答え**: （　　　）

> [!TIP]
>
> **本試験では**
> 負のマージンの値や方向、選択肢を変更した問題が出題されます。

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**正解：A**

### 解説

負のマージン（`margin-bottom: -30px;`）を使うと、**次の要素との間隔を詰める**ことができます。

この問題では：

- HTMLで `.box1` と `.box2` が縦に並んで記述されています
- `.box1` が最初に配置される（幅200px、高さ100px、赤色）
- 通常、`.box2` は `.box1` の真下（`.box1` の下端のすぐ下）に配置されます
- しかし、`.box1` に `margin-bottom: -30px;` が指定されているため、`.box1` の下マージンが-30pxとなり、次の要素（`.box2`）が**上方向に30px引き寄せられます**
- その結果、`.box2` が `.box1` の一部と**重なって**表示されます

各選択肢の解説：

- A **正解**。`margin-bottom: -30px;` により `.box2` が上方向に30px引き寄せられ、`.box1` と重なります
- B 誤り。`.box2` は `.box1` の完全に上側ではなく、一部重なる位置に配置されます
- C 誤り。`margin-bottom` は上下方向の余白を制御するプロパティで、左右には影響しません
- D 誤り。負のマージンは要素を近づける（重ねる）効果があり、離す効果はありません

負のマージンは、要素を重ねたり、隙間を詰めたりする高度なレイアウトテクニックで、カードを少し重ねて表示したい場合などに使われます。

</Solution>
</Exercise>

## 問題10：display プロパティ（2点）

<Exercise>
次のCSSが適用された要素の表示について、正しい説明を選びなさい。

```css
.item {
  display: inline-block;
  width: 100px;
  height: 50px;
}
```

A. 要素は縦に並び、幅と高さを指定できる  
B. 要素は横に並び、幅と高さを指定できる  
C. 要素は横に並ぶが、幅と高さは指定できない  
D. 要素は縦に並ぶが、幅と高さは指定できない

**答え**: （　　　）

> [!TIP]
>
> **本試験では**
> display の値や説明の組み合わせを変更した問題が出題されます（`block`, `inline`, `inline-block` のいずれか、または全て）。

> [!NOTE]
>
> **採点基準・配点**
>
> - 正答：2点

<Solution>
### 解答
**正解：B**

### 解説

`display: inline-block` は、**横に並び**、かつ **`width` や `height` を自由に設定できる**表示形式です。

主な特徴：

- `inline` のように横に並ぶ（改行されない）
- `block` のように `width` や `height` を指定できる
- `inline` と `block` の良いところを組み合わせた表示形式
- ボタンやカードを横に並べる時に便利

各選択肢の解説：

- A 誤り。`inline-block` は横に並びます。縦に並ぶのは `block` です
- B **正解**。横に並び、幅と高さを指定できるのが `inline-block` の特徴です
- C 誤り。`inline-block` は幅と高さを指定できます。指定できないのは `inline` です
- D 誤り。`inline-block` は横に並びます。また、幅と高さは指定できます

他の `display` の値：

- `block`: 縦に並び、`width` や `height` を指定できる（例：`<div>`, `<p>`）
- `inline`: 横に並ぶが、`width` や `height` を指定できない（例：`<span>`, `<a>`）
  </Solution>
  </Exercise>
