# 前期 中間試験 対策問題集

この問題集は、中間試験（本試験）と同じ考え方で解ける問題を先に練習するためのものです。  
各問題の「本試験では」を読み、学習の方向性を確認してください。

<Exercise title="問題1：ファイル名の構成と拡張子">
ファイル名は、「名前部分」と「拡張子」から構成されています。以下の問いに答えなさい。

1. ファイル名の「拡張子」とは何か、説明せよ。
2. 以下の各ファイルの拡張子を答えよ。また、HTMLファイルはどれか答えよ。

- `index.html`
- `style.css`
- `readme.txt`

> [!TIP]
>
> **本試験では**
> 〇〇ファイルの拡張子は何か？ と答えさせる問題になります。  
> ファイルの種類と、拡張子の対応を理解しておく必要があります。

<Solution>
### 解答・解説

**1. 拡張子とは**  
拡張子とは、ファイル名の末尾にある「.」（ドット）以降の文字列で、そのファイルの種類や形式を表すものです。

**具体例：**
- `document.pdf` → 拡張子は「pdf」（PDFファイル）
- `photo.jpg` → 拡張子は「jpg」（JPEG画像ファイル）
- `music.mp3` → 拡張子は「mp3」（音楽ファイル）

**2. 各ファイルの拡張子**
- `index.html` → 拡張子：**html**
- `style.css` → 拡張子：**css**
- `readme.txt` → 拡張子：**txt**

**HTMLファイルは：** `index.html`

**重要なファイル拡張子：**
- `.html` → HTMLファイル（ウェブページ）
- `.css` → CSSファイル（スタイルシート）
- `.js` → JavaScriptファイル（プログラム）
- `.txt` → テキストファイル（文章）
- `.jpg`、`.png` → 画像ファイル
</Solution>
</Exercise>

<Exercise title="問題2：HTMLの基本構造">
以下のHTMLのコードには文法上の誤りがあります。正しい文法となるように修正しなさい。

```html
<!DOCTYPE html>
<html>
  <head>
    <title>ページのタイトル</title>
    <body>
      <h1>こんにちは</h1>
    </body>
  </head>
</html>
```

> [!TIP]
>
> **本試験では**
> 修正問題ではなく、選択式で文法上の誤りのないHTMLを選ぶ形式で出題されます。  
> 4つの選択肢から正しいHTMLの基本構造を選ぶ問題になります。

<Solution>
### 解答

**間違い：** `<body>`タグが`<head>`タグの中に入っている

**正しいHTML構造：**
```html
<!DOCTYPE html>
<html>
  <head>
    <title>ページのタイトル</title>
  </head>
  <body>
    <h1>こんにちは</h1>
  </body>
</html>
```

### 解説

**HTMLの基本構造の覚え方：**
1. `<!DOCTYPE html>` → HTMLであることを宣言
2. `<html>` → HTMLドキュメント全体を囲む
3. `<head>` → ページの情報（タイトル、CSS、メタデータなど）
4. `<body>` → ページに表示される内容

**入れ子の順番：**
```
html
|-- head
|   |-- title
|   `-- その他のメタデータ
`-- body
    `-- 表示される内容
```

**よくある間違い：**
- `<body>`を`<head>`の中に書く
- `<!DOCTYPE html>`を忘れる
- 閉じタグを忘れる
</Solution>
</Exercise>

<Exercise title="問題3～7：タグの意味（テキスト関連）">
以下のタグがそれぞれどのような意味・目的で使われるか、簡潔に一言で答えよ。

- `br`
- `h1`
- `strong`
- `p`
- `small`

> [!TIP]
>
> **本試験では**
> タグの意味を説明する問題ではなく、選択式で「〇〇を表すHTMLタグを選べ」という形式で出題されます。  
> 複数の選択肢からタグを選ぶ問題になります。

<Solution>
### 解答・解説

**各タグの意味：**

- **`<br>`** → **改行**を表す
  ```html
  <p>1行目<br>2行目</p>
  ```
  表示例：
  ```
  1行目
  2行目
  ```

- **`<h1>`** → **見出し1**（最も重要な見出し）
  ```html
  <h1>メインタイトル</h1>
  <h2>サブタイトル</h2>
  ```

- **`<strong>`** → **重要**なテキストの強調
  ```html
  <p>この商品は<strong>送料無料</strong>です</p>
  ```
  表示例：この商品は**送料無料**です

- **`<p>`** → **段落**（文章のまとまり）
  ```html
  <p>これは1つ目の段落です。</p>
  <p>これは2つ目の段落です。</p>
  ```

- **`<small>`** → **補足情報**（小さい文字で表示）
  ```html
  <p>商品価格：1000円 <small>※税込み</small></p>
  ```

**覚え方：**
- `h1` = Heading 1（見出し1）
- `p` = Paragraph（段落）
- `br` = Break（改行）
- `strong` = 強い（重要）
- `small` = 小さい（補足）
</Solution>
</Exercise>

<Exercise title="問題3～7：タグの意味（構造・ナビゲーション）">
以下のタグがそれぞれどのような意味・目的で使われるか、簡潔に一言で答えよ。

- `header`
- `main`
- `footer`
- `nav`
- `section`

> [!TIP]
>
> **本試験では**
> 上記と同様に、選択式でタグを選ぶ形式になります。

<Solution>
### 解答・解説

**各タグの意味：**

- **`<header>`** → **ヘッダー**（ページ上部の情報）
  ```html
  <header>
    <h1>サイトタイトル</h1>
    <nav>ナビゲーション</nav>
  </header>
  ```

- **`<main>`** → **メインコンテンツ**（ページの主要な内容）
  ```html
  <main>
    <h1>記事タイトル</h1>
    <p>記事の内容...</p>
  </main>
  ```

- **`<footer>`** → **フッター**（ページ下部の情報）
  ```html
  <footer>
    <p>&copy; 2025 会社名. All rights reserved.</p>
  </footer>
  ```

- **`<nav>`** → **ナビゲーション**（メニューやリンク集）
  ```html
  <nav>
    <ul>
      <li><a href="#home">ホーム</a></li>
      <li><a href="#about">会社概要</a></li>
    </ul>
  </nav>
  ```

- **`<section>`** → **セクション**（内容のまとまり）
  ```html
  <section>
    <h2>お知らせ</h2>
    <p>最新のお知らせ内容...</p>
  </section>
  ```

**ページ構造の例：**
```html
<header>
  <h1>タイトル</h1>
  <nav>ナビゲーション</nav>
</header>
<main>
  <section>セクション1</section>
  <section>セクション2</section>
</main>
<footer>フッター</footer>
```
</Solution>
</Exercise>

<Exercise title="問題3～7：タグの意味（リスト）">
以下のタグがそれぞれどのような意味・目的で使われるか、簡潔に一言で答えよ。

- `ul`
- `ol`
- `li`

> [!TIP]
>
> **本試験では**
> 上記と同様に、選択式でタグを選ぶ形式になります。

<Solution>
### 解答・解説

**各タグの意味：**

- **`<ul>`** → **順序なしリスト**（箇条書き、・で表示）
  ```html
  <ul>
    <li>りんご</li>
    <li>みかん</li>
    <li>ばなな</li>
  </ul>
  ```
  表示例：
  ```
  ・ りんご
  ・ みかん
  ・ ばなな
  ```

- **`<ol>`** → **順序ありリスト**（番号付きリスト、1.2.3.で表示）
  ```html
  <ol>
    <li>材料を準備する</li>
    <li>調理する</li>
    <li>盛り付ける</li>
  </ol>
  ```
  表示例：
  ```
  1. 材料を準備する
  2. 調理する
  3. 盛り付ける
  ```

- **`<li>`** → **リストの項目**（リストの各要素）
  ```html
  <ul>
    <li>これが1つ目の項目</li>
    <li>これが2つ目の項目</li>
  </ul>
  ```

**覚え方：**
- `ul` = Unordered List（順序なしリスト）
- `ol` = Ordered List（順序ありリスト）
- `li` = List Item（リスト項目）

**使い分け：**
- **手順や順番が重要** → `<ol>`を使用
- **単なる箇条書き** → `<ul>`を使用
</Solution>
</Exercise>

<Exercise title="問題3～7：タグの意味（リンク・画像）">
以下のタグがそれぞれどのような意味・目的で使われるか、簡潔に一言で答えよ。

- `a`
- `img`

> [!TIP]
>
> **本試験では**
> 上記と同様に、選択式でタグを選ぶ形式になります。

<Solution>
### 解答・解説

**各タグの意味：**

- **`<a>`** → **リンク**（他のページや場所への移動）
  ```html
  <!-- 外部サイトへのリンク -->
  <a href="https://www.google.com">Googleで検索</a>

  <!-- 同じページ内の別の場所へのリンク -->
  <a href="#section1">セクション1へ移動</a>

  <!-- 新しいタブで開く -->
  <a href="https://example.com" target="_blank">外部サイト</a>
  ```

- **`<img>`** → **画像**の表示
  ```html
  <!-- 基本的な画像表示 -->
  <img src="photo.jpg" alt="写真の説明">

  <!-- フォルダ内の画像 -->
  <img src="images/logo.png" alt="会社ロゴ">

  <!-- サイズ指定 -->
  <img src="banner.jpg" alt="バナー" width="300" height="200">
  ```

**重要な属性：**

**`<a>`タグの主要属性：**
- `href` → リンク先のURL（必須）
- `target="_blank"` → 新しいタブで開く

**`<img>`タグの主要属性：**
- `src` → 画像ファイルのパス（必須）
- `alt` → 代替テキスト（必須、画像が表示されない時に表示）

**覚え方：**
- `a` = Anchor（アンカー、錨）
- `img` = Image（画像）
</Solution>
</Exercise>

<Exercise title="問題8：順序付きリストのマークアップ">
以下は「冷やし中華を作る手順」の原稿である。この手順を順序付きリスト（`<ol>`）を使ってHTMLでマークアップせよ。  
原稿内の番号「1.」「2.」はHTMLには書いてはいけない（`<ol>`タグで適切にマークアップすると、自動で表示されます）。

```
1. 麺をゆでる
2. 具材（卵、きゅうり、ハムなど）を切る
3. 麺を冷水でしめる
4. 麺と具材を盛りつけ、タレをかける
```

> [!TIP]
>
> **本試験では**
> 同じく自由記述式で順序付きリストのマークアップが出題されますが、マークアップする原稿が変わります。  
> どのような原稿でも、順序付きリストとしてマークアップできるようになっておく必要があります。

<Solution>
### 解答
```html
<ol>
  <li>麺をゆでる</li>
  <li>具材（卵、きゅうり、ハムなど）を切る</li>
  <li>麺を冷水でしめる</li>
  <li>麺と具材を盛りつけ、タレをかける</li>
</ol>
```

### 解説

1. **`<ol>`タグで全体を囲む** → 順序付きリスト（Ordered List）
2. **各項目を`<li>`で囲む** → リスト項目（List Item）
3. **元の番号（1. 2. 3. 4.）は削除** → `<ol>`が自動で番号を付ける

**手順の覚え方：**
1. 原稿から番号を削除
2. 各項目を`<li></li>`で囲む
3. 全体を`<ol></ol>`で囲む

**他の例：**

原稿：
```
1. サイトにアクセス
2. ログインする
3. 商品を選ぶ
4. 決済する
```

HTML：
```html
<ol>
  <li>サイトにアクセス</li>
  <li>ログインする</li>
  <li>商品を選ぶ</li>
  <li>決済する</li>
</ol>
```

**注意点：**
- 原稿の番号は必ず削除する
- `<ol>`内には`<li>`以外は入れない
</Solution>
</Exercise>

<Exercise title="問題9：画像の表示（img要素）">
以下のようなフォルダ構成になっている。

```
public
|-- index.html
`-- assets
    `-- bird.png
```

このとき、index.html に画像 bird.png を正しく表示するには、`<img>`要素をどのように書けばよいか。img要素のみを答えよ。  
alt属性の値は「青い鳥」とすること。

> [!TIP]
>
> **本試験では**
> 同じく自由記述式で画像表示の問題が出題されますが、ファイル名やフォルダ名、alt属性の値が変わります。  
> 正しいパスの指定方法、alt属性の指定方法を理解しておく必要があります。

<Solution>
### 解答
```html
<img src="assets/bird.png" alt="青い鳥">
```

### 解説

**パスの考え方：**
1. `index.html`の位置から見て、`bird.png`はどこにある？
2. `index.html`と同じ階層に`assets`フォルダがある
3. `assets`フォルダの中に`bird.png`がある
4. よって、パスは`assets/bird.png`

**フォルダ構造の読み方：**
```
public (現在のフォルダ)
|-- index.html  <-- ここから見る
`-- assets     <-- 同じ階層のフォルダ
    `-- bird.png
```

**相対パスの例：**

**例1：**
```
project
|-- index.html
`-- photo.jpg
```
→ `<img src="photo.jpg" alt="写真">`

**例2：**
```
project
|-- index.html
`-- images
    `-- logo.png
```
→ `<img src="images/logo.png" alt="ロゴ">`

**例3：**
```
project
|-- pages
|   `-- about.html
`-- images
    `-- banner.jpg
```
about.htmlから見た場合：
→ `<img src="../images/banner.jpg" alt="バナー">`  
（`../`は一つ上の階層を意味する）

**重要なポイント：**
- `src`属性：画像ファイルのパス（必須）
- `alt`属性：代替テキスト（必須）
- パスは現在のHTMLファイルからの相対位置で指定
</Solution>
</Exercise>

<Exercise title="問題10：リンクのマークアップ（a要素）">
以下の条件にしたがって、リンクを表すHTML要素を記述せよ。

- リンク先のURL：`https://google.com`
- 表示するリンクテキスト：「Googleで検索」
- リンクは**新しいタブ**で開くようにすること

> [!TIP]
>
> **本試験では**
> 同じく自由記述式で外部リンクの記述が出題されますが、リンク先のURLや、表示するリンクテキストが変わります。  
> URLやリンクテキストが変わっても、正しくa要素をマークアップできるようにしておく必要があります。

<Solution>
### 解答
```html
<a href="https://google.com" target="_blank">Googleで検索</a>
```

### 解説

**`<a>`タグの構成要素：**
1. **`href`属性** → リンク先のURL
2. **`target="_blank"`属性** → 新しいタブで開く
3. **リンクテキスト** → クリックできる文字（タグの中身）

**各属性の詳細：**

**`href`属性：**
- 外部サイト：`href="https://example.com"`
- 同じサイト内：`href="about.html"`
- ページ内リンク：`href="#section1"`

**`target`属性：**
- `target="_blank"` → 新しいタブで開く

**他の例：**

**例1：同じタブで開く外部リンク**
```html
<a href="https://yahoo.co.jp">Yahoo!へ移動</a>
```

**例2：ページ内リンク**
```html
<a href="#top">ページトップへ</a>
```

**よくある間違い：**
- `href`属性を忘れる
- URLにプロトコル（https://）を忘れる
- 新しいタブで開きたいのに`target="_blank"`を忘れる
- リンクテキストを忘れる

**覚え方：**
```html
<a href="どこへ" target="どのように">何を表示</a>
```
</Solution>
</Exercise>
