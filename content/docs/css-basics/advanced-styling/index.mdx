## 演習1：HTMLを書こう

<Exercise>

完成見本のHTMLのみを書いてください。CSSはまだ書かないでください。

手順1〜3では、まだ文章のテキストは書かないでください。まずHTMLの構造だけを作ります。

### 1. HTMLの基本構造を書く

`index.html`を作り、以下の要素を使ってHTMLの基本構造を書いてください。

- `<!DOCTYPE html>`
- `html`
- `head`
- `title`
- `body`

### 2. ページを大きく3つに分ける

`body`の中を、次の3つの要素に分けてください。

- ページ上部：`header`
- ページの中心となる内容：`main`
- ページ下部：`footer`

### 3. 内容のまとまりを作る

`main`の中を、内容のまとまりごとに分けてください。

見出しがあるまとまりには`section`を使います。  
見出しがないまとまりには`div`を使います。

### 4. 見出しや文章を書く

プレビュー内の文章をコピーし、内容に合ったHTML要素を使ってマークアップしてください。

- ページ全体の見出し：`h1`（1ページに1つを推奨）
- 各まとまりの見出し：`h2`
- 文章：`p`
- 項目の一覧：`ul`と`li`

<Hint>

まず、`body`の中を次の形に分けてください。

```html
<body>
    <header>
    </header>

    <main>
        <section>
        </section>

        <section>
        </section>

        <section>
        </section>
    </main>

    <footer>
    </footer>
</body>
```

その後、それぞれの中に見出し、文章、一覧を追加してください。

</Hint>

## 演習2：ページ全体とヘッダーを整えよう

<Exercise>

`style.css`を作り、ページ全体とヘッダーの見た目を整えてください。

実務では、ページ全体に共通する基本設定を除き、特定の見た目を付けるときはクラスを使うことが一般的です。

今回も、`body`の基本設定以外は、要素にクラスを付けてCSSを指定してください。

クラスを使うと、一部の要素にだけ特定のスタイルを適用したり、複数の要素に同じスタイルを適用することが楽にできます。

色は、`red`や`blue`などのカラーネームで指定してください。

### 1. CSSを読み込む

`head`の中で`style.css`を読み込んでください。

### 2. ヘッダーにクラスを付ける

次のクラス名を使ってください。

- `top`：ヘッダー全体
- `label`：ヘッダー上部の英字
- `title`：ページ全体の見出し
- `lead`：見出しの下にある文章

### 3. ページ全体とヘッダーのCSSを書く

次の順番でCSSを書いてください。

1. `body`
2. `.top`
3. `.label`
4. `.title`
5. `.lead`

完成見本を確認し、次の部分を整えてください。

- ページ全体の背景色、文字色、行間
- ヘッダーの背景色、文字色、内側の余白
- ヘッダー内の文字の配置
- 英字、見出し、文章の文字サイズと余白

<Hint>

HTMLには、次のようにクラスを付けます。

```html
<header class="top">

    <p class="lead">

    </p>
</header>
```


## 演習3：メイン部分を整えよう

<Exercise>

メイン部分にクラスを付け、3つの内容を同じデザインの箱にしてください。

### 1. メイン部分にクラスを付ける

`main`に`content`クラスを付けてください。

完成見本を確認し、メイン部分の幅、位置、上下の間隔を整えてください。

### 2. 同じ見た目の要素を探す

「イベントについて」「開催情報」「参加方法」の3つは、同じ見た目の箱になっています。

3つの`section`すべてに`box`クラスを付けてください。

同じ見た目の要素に同じクラスを付けると、1つのCSSでまとめて見た目を変更できます。

### 3. メイン部分のCSSを書く

`.content`を書いた後に、`.box`を書いてください。

完成見本を確認し、次の部分を整えてください。

- メイン部分の幅と左右の位置
- 箱の背景色
- 箱の枠線
- 箱の内側の余白
- 箱同士の間隔

<Hint>

HTMLには、次のようにクラスを付けます。

```html
<main class="content">
    <section class="box">
    </section>

    <section class="box">
    </section>

    <section class="box">
    </section>
</main>
```

幅を指定した要素を左右中央に配置するときは、`width`と`margin: 0 auto;`を組み合わせます。

### 2. フッターにクラスを付ける

次のクラス名を使ってください。

- `bottom`：フッター全体
- `copy`：フッター内の文章

### 3. 見出しとフッターのCSSを書く

次の順番でCSSを書いてください。

1. `.subtitle`
2. `.list`
3. `.bottom`
4. `.copy`

CSSは、外側から内側へ、ページの上から下へ、大きな部分から細かい部分へ書くと進めやすくなります。

最後に完成見本と見比べ、文字の大きさや余白を調整してください。

<Hint>

```html
<h2 class="subtitle">イベントについて</h2>
<h2 class="subtitle">開催情報</h2>
<h2 class="subtitle">参加方法</h2>
```

フッターには、次のようにクラスを付けます。

```html
<footer class="bottom">
```

- 大きなまとまりの見出しに`h2`を使う
- 各作品の見出しに`h3`を使う
- 文章に`p`を使う

### クラスとCSS

同じ見た目の3つの作品には、同じクラスを付けてください。

注目されている1つの作品には、共通のクラスに加えて、別のクラスを付けてください。

CSSは、共通のスタイルを先に書き、一部だけ異なるスタイルを後に書いてください。

色は、`red`や`blue`などのカラーネームで指定してください。

<Hint>

「上映作品」の`section`の中に、3つの`section`があります。

```html
<section>
    <h2>上映作品</h2>

    <section>
        <h3>作品名</h3>
    </section>

    <section>
        <h3>作品名</h3>
    </section>

    <section>
        <h3>作品名</h3>
    </section>
</section>
```

3つの作品に共通するクラスを付け、注目作品だけクラスを追加します。

```html
<section class="movie">
</section>

<section class="movie pick">
</section>

<section class="movie">
</section>
```

CSSは、`.movie`を先に書き、`.pick`を後に書きます。
