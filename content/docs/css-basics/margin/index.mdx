---
title: カードの間隔を整えよう
authoringMode: tutorial
---

前回は、`width`・`height`・`border`・`padding` を使って、1 枚の商品カードの見た目を作りました。

今回は、カードを **複数枚並べたときの間隔** を整えます。カードの中ではなく、カードとカードの **外側のすき間** を作るために、`margin` を使います。

---

<Prerequisites>
- [カードを作ろう](../box-model/index.mdx) レッスンを完了していること（`width` / `height` / `border` / `padding` を使えること）
- `class` と `.クラス名` を使って、特定の要素に CSS を指定できること
- CSS では、後に書いた指定が前の指定を上書きすることがあると知っていること
</Prerequisites>

---

<Section title="完成形を見る" goal="margin を使って、カード一覧の間隔と配置を整えた完成形を確認する">

まずは、今回作る完成形を見ます。

今回は、カードの中身を作り込むことよりも、**カード一覧全体が読みやすく見える間隔** を作ることが目標です。

<CodePreview
    previewVisible={true}
    htmlVisible={false}
    cssVisible={false}
>

```html
<div class="card-list">
    <div class="card">チョコドーナツ</div>
    <div class="card">カフェラテ</div>
    <div class="card last-card">サンドイッチ</div>
</div>
```

```css
.card-list {
    width: 320px;
    margin: 0 auto;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

完成形では、次の 3 つを `margin` で整えています。

- カードとカードのあいだ
- 最後のカードの下の余白
- カード一覧全体の左右の位置

このように、`margin` は **要素どうしの距離** を整えるために使います。

</Section>

---

<Section title="margin は外側の余白" goal="`margin` が border の外側にある余白であることを理解する">

`padding` と `margin` は、どちらも余白を作る CSS です。ただし、余白ができる場所が違います。

<Concept title="`padding` と `margin` の違い">

- `padding`：`border` の **内側** の余白
- `margin`：`border` の **外側** の余白

</Concept>

### padding だけだと、カード同士は近いまま

次の例では、カードに `padding` はありますが、`margin` はありません。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    background-color: #fff7ed;
}
```

</CodePreview>

`padding` はカードの **内側** を広げます。文字と枠線のあいだは広がりますが、カードとカードのあいだは広がりません。

</Section>

---

<Section title="カード同士の間隔を作る" goal="下側の外側余白を作る `margin-bottom` を使えるようになる">

前の例では、`padding` を指定してもカード同士のあいだは広がりませんでした。

カード同士のあいだを広げたいときは、`.card` に `margin-bottom` を指定します。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}
```

</CodePreview>

`margin-bottom: 16px;` は、要素の **下側の外側** に 16px の余白を作ります。

そのため、上のカードと下のカードのあいだにすき間ができます。

<Checkpoint title="ここまでの確認">

- カードの内側を広げたいときは `padding` を使う
- カード同士のあいだを空けたいときは `margin` を使う
- 下側の外側余白は `margin-bottom` で作る

</Checkpoint>

</Section>

---

<Section title="最後のカードだけ余白をなくす" goal="class を2つ付けて、最後のカードだけ下の余白をなくす">

`.card` に `margin-bottom` を指定すると、すべてのカードの下に余白ができます。

カードの下に何もないと、最後のカードの余白は見えにくいです。そこで、カード一覧の下に「次の内容」を置いて確認します。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>

<div class="next-content">ここから次の内容です</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.next-content {
    padding: 8px;
    background-color: #fde047;
}
```

</CodePreview>

3 枚目のカードにも `margin-bottom: 16px;` が効いているため、最後のカードと次の内容のあいだにも余白ができます。

最後のカードの下だけ余白をなくしたいときは、最後のカードに class を追加します。

```html
<div class="card last-card">サンドイッチ</div>
```

`class="card last-card"` のように、class はスペースで区切ると複数つけられます。

- `card`：すべてのカードに共通する見た目
- `last-card`：最後のカードだけ変える見た目

次のように、`.last-card` で最後のカードだけ `margin-bottom` を `0` にします。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card last-card">サンドイッチ</div>

<div class="next-content">ここから次の内容です</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}

.next-content {
    padding: 8px;
    background-color: #fde047;
}
```

</CodePreview>

最後のカードには、`card` と `last-card` の 2 つの class が付いています。

そのため、最後のカードには `.card` の CSS も、`.last-card` の CSS も当たります。

- `.card` では、`margin-bottom: 16px;` と指定している
- `.last-card` では、`margin-bottom: 0;` と指定している

この例では、`.card` と `.last-card` は、どちらも **同じ要素に対する class セレクタの指定** です。

同じ要素に対して、同じ `margin-bottom` を指定しているので、**後ろに書いた指定** が最後に効きます。

そのため、`.last-card` は `.card` より後ろに書きます。

<Checkpoint title="ここまでの確認">

- 最後のカードには `class="card last-card"` のように class を 2 つ付ける
- `.last-card` で `margin-bottom: 0;` を指定する
- `.last-card` は `.card` より後ろに書く

</Checkpoint>

</Section>

<Section title="カード一覧を中央に置く" goal="`width` と `margin: 0 auto;` を組み合わせて、まとまり全体を中央に配置する">

カード一覧を横幅いっぱいではなく、決まった幅のまとまりとして見せたいことがあります。

まず、`.card-list` に `width: 320px;` だけを指定してみます。

<CodePreview>

```html
<div class="card-list">
    <div class="card">チョコドーナツ</div>
    <div class="card">カフェラテ</div>
    <div class="card last-card">サンドイッチ</div>
</div>
```

```css
.card-list {
    width: 320px;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

カード一覧の幅は 320px になります。ただし、このままだとカード一覧は画面の左側に寄っています。

カード一覧全体を中央に置きたいときは、`.card-list` に `margin: 0 auto;` を追加します。

<CodePreview>

```html
<div class="card-list">
    <div class="card">チョコドーナツ</div>
    <div class="card">カフェラテ</div>
    <div class="card last-card">サンドイッチ</div>
</div>
```

```css
.card-list {
    width: 320px;
    margin: 0 auto;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

`margin: 0 auto;` は、次の意味です。

- 上下の余白：`0`
- 左右の余白：`auto`

左右の余白を自動で同じくらいにすることで、要素が中央に置かれます。

<Concept title="中央寄せの注意点">

`margin: 0 auto;` で中央に寄せるには、`width` が必要です。

横幅が決まっていないと、どのくらい左右に余白を作ればよいか決められないためです。

</Concept>

</Section>

<Section title="HTMLタグには最初から margin がある" goal="自分で CSS を書いていなくても、HTMLタグに最初から余白があることを確認する">

ここまでは、`div` に class を付けて、自分で `margin` を指定してきました。

しかし、HTMLタグの中には、ブラウザが最初から余白を付けているものがあります。

たとえば、`h2` や `p` は、自分で `margin` を書いていなくても、上下に余白が付いて見えます。

### `h2` と `p` の margin を書かなくても余白がある

<CodePreview>

```html
<h2>おすすめ商品</h2>
<p>今日のおすすめを紹介します。</p>

<div class="next-content">ここから次の内容です</div>
```

```css
.next-content {
    padding: 8px;
    background-color: #fde047;
}
```

</CodePreview>

`h2` や `p` に margin を書いていなくても、見出しと段落のまわりに余白があります。

これは、ブラウザが `h2` や `p` に最初から付けている余白です。

### 自分で margin を指定する

見た目を自分で整えたいときは、最初から付いている余白に任せず、自分で `margin-top` や `margin-bottom` を指定します。

<CodePreview>

```html
<h2>おすすめ商品</h2>
<p>今日のおすすめを紹介します。</p>

<div class="next-content">ここから次の内容です</div>
```

```css
h2 {
    margin-top: 0;
    margin-bottom: 8px;
}

p {
    margin-top: 0;
    margin-bottom: 24px;
}

.next-content {
    padding: 8px;
    background-color: #fde047;
}
```

</CodePreview>

この例では、上側の余白を `0` にして、下側の余白だけを自分で決めています。

<Checkpoint title="ここまでの確認">

- `h2` や `p` には、ブラウザが最初から margin を付けている
- そのまま使ってもよいが、見た目をそろえたいときは自分で指定する
- 上側の余白は `margin-top`、下側の余白は `margin-bottom` で指定できる

</Checkpoint>

</Section>

<Section title="完成チェックと困ったとき" goal="margin が意図した場所に効いているか、自分で確認できる">

最後に、できたところを確認しましょう。

**完成チェック**:

- [ ] `padding` と `margin` の違いを説明できる
- [ ] カード同士のあいだを `margin-bottom` で空けられる
- [ ] 最後のカードだけ `margin-bottom: 0;` にできる
- [ ] `width` と `margin: 0 auto;` でカード一覧を中央に置ける
- [ ] `h2` や `p` に最初から margin があることを知っている
- [ ] `margin-top` と `margin-bottom` で、HTMLタグの余白を自分で指定できる
- [ ] 商品を追加したときに、`last-card` を最後のカードへ付け替えられる
- [ ] `margin` を使って、ページ内のまとまり同士の間隔を整えられる

<Recovery title="中央に寄らないとき">

`margin: 0 auto;` を書いても中央に寄らないときは、次を確認してください。

- 中央に置きたい要素に `width` を指定しているか
- `margin: 0 auto;` を、カード1枚ではなく、中央に置きたいまとまりに書いているか
- class 名の先頭に `.` をつけて CSS を書いているか

</Recovery>

<Recovery title="最後のカードの余白が消えないとき">

最後のカードの下に余白が残るときは、次を確認してください。

- 最後のカードに `class="card last-card"` が付いているか
- `.last-card` に `margin-bottom: 0;` が書かれているか
- `.last-card` を `.card` より後ろに書いているか

</Recovery>

<Recovery title="カード同士の間隔が変わらないとき">

カード同士の間隔が変わらないときは、次を確認してください。

- `padding` ではなく `margin-bottom` を書いているか
- `margin-bottom: 16px;` のように、数字のあとに `px` を書いているか
- CSS ファイルを保存しているか
- ブラウザを再読み込みしているか

</Recovery>

### AI に質問するときのコツ

:::tip[確認手順を聞く]
AI に「完成コードを全部書いて」と頼むと、どこを直せばよかったのか分かりにくくなります。**「どこを確認すればよいか」を順番に聞く** と、自分で直す練習になります。
:::
