---
title: カードの間隔を整えよう
authoringMode: tutorial
---

前回は、`width`・`height`・`border`・`padding` を使って、1 枚の商品カードの見た目を作りました。

今回は、カードを **複数枚並べたときの間隔** を整えます。カードの中ではなく、カードとカードの **外側のすき間** を作るために、`margin` を使います。

---

<Prerequisites>
- [カードを作ろう](../box-model/index.mdx) レッスンを完了していること（`width` / `height` / `border` / `padding` を使えること）
- `class` と `.クラス名` を使って、特定の要素に CSS を指定できること
</Prerequisites>

---

<Section title="完成形を見る" goal="margin を使って、カード一覧の間隔と配置を整えた完成形を確認する">

まずは、今回作る完成形を見ます。

今回は、カードの中身を作り込むことよりも、**カード一覧全体が読みやすく見える間隔** を作ることが目標です。

<CodePreview
    previewVisible={true}
    htmlVisible={false}
    cssVisible={false}
>

```html
<div class="shop-page">
    <h2 class="page-title">おすすめ商品</h2>
    <p class="page-lead">今日のおすすめを3つ紹介します。</p>

    <div class="card-list">
        <div class="card">
            <h3>チョコドーナツ</h3>
            <p>甘いチョコをかけた人気商品です。</p>
        </div>

        <div class="card">
            <h3>カフェラテ</h3>
            <p>ミルクをたっぷり使ったドリンクです。</p>
        </div>

        <div class="card last-card">
            <h3>サンドイッチ</h3>
            <p>軽い昼食にぴったりの商品です。</p>
        </div>
    </div>
</div>
```

```css
.shop-page {
    width: 360px;
    margin: 0 auto;
}

.page-title {
    margin-bottom: 8px;
}

.page-lead {
    margin-bottom: 24px;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

完成形では、次の 3 つを `margin` で整えています。

- 見出しと説明文のあいだ
- 説明文とカード一覧のあいだ
- カードとカードのあいだ

このように、`margin` は **要素どうしの距離** を整えるために使います。

</Section>

---

<Section title="margin は外側の余白" goal="`margin` が border の外側にある余白であることを理解する">

`padding` と `margin` は、どちらも余白を作る CSS です。ただし、余白ができる場所が違います。

<Concept title="`padding` と `margin` の違い">

- `padding`：`border` の **内側** の余白
- `margin`：`border` の **外側** の余白

</Concept>

### padding だけだと、カード同士は近いまま

次の例では、カードに `padding` はありますが、`margin` はありません。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    background-color: #fff7ed;
}
```

</CodePreview>

`padding` はカードの **内側** を広げます。文字と枠線のあいだは広がりますが、カードとカードのあいだは広がりません。

### margin-bottom を足すと、カード同士が離れる

カード同士のあいだを広げたいときは、`margin-bottom` を使います。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}
```

</CodePreview>

`margin-bottom: 16px;` は、要素の **下側の外側** に 16px の余白を作ります。

そのため、上のカードと下のカードのあいだにすき間ができます。

</Section>

---

<Section title="最後のカードだけ余白をなくす" goal="共通の class と追加の class を組み合わせて、一部だけ見た目を変える">

`.card` に `margin-bottom` を指定すると、すべてのカードの下に余白ができます。

ただし、最後のカードの下には、余計な余白がいらないことがあります。

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}
```

</CodePreview>

最後のカードだけ変えたいときは、HTML に class を追加します。

```html
<div class="card last-card">サンドイッチ</div>
```

`class="card last-card"` のように、class はスペースで区切ると複数つけられます。

- `card`：すべてのカードに共通する見た目
- `last-card`：最後のカードだけ変える見た目

<CodePreview>

```html
<div class="card">チョコドーナツ</div>
<div class="card">カフェラテ</div>
<div class="card last-card">サンドイッチ</div>
```

```css
.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

`.last-card` で `margin-bottom: 0;` と書くと、最後のカードだけ下の余白をなくせます。

<Checkpoint title="ここまでの確認">

- カード同士のあいだを空けるときは、`padding` ではなく `margin` を使う
- 下側の外側余白は `margin-bottom` で作る
- 一部だけ変えたいときは、追加の class を使う

</Checkpoint>

</Section>

---

<Section title="カード一覧を中央に置く" goal="`width` と `margin: 0 auto;` を組み合わせて、まとまり全体を中央に配置する">

カード一覧が画面の左に寄っていると、少し見づらく感じることがあります。

カード一覧全体を中央に置きたいときは、カードを包む要素を作ります。

```html
<div class="card-list">
    <div class="card">チョコドーナツ</div>
    <div class="card">カフェラテ</div>
    <div class="card last-card">サンドイッチ</div>
</div>
```

この `.card-list` に、横幅と `margin: 0 auto;` を指定します。

<CodePreview>

```html
<div class="card-list">
    <div class="card">チョコドーナツ</div>
    <div class="card">カフェラテ</div>
    <div class="card last-card">サンドイッチ</div>
</div>
```

```css
.card-list {
    width: 320px;
    margin: 0 auto;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

`margin: 0 auto;` は、次の意味です。

- 上下の余白：`0`
- 左右の余白：`auto`

左右の余白を自動で同じくらいにすることで、要素が中央に置かれます。

<Concept title="中央寄せの注意点">

`margin: 0 auto;` で中央に寄せるには、`width` が必要です。

横幅が決まっていないと、どのくらい左右に余白を作ればよいか決められないためです。

</Concept>

</Section>

---

<Section title="見出しとカード一覧の距離を整える" goal="カード同士だけでなく、見出しや説明文との距離も margin で調整できることを理解する">

`margin` は、カード同士の間隔だけでなく、見出しや説明文との距離を整えるときにも使えます。

たとえば、見出しと説明文のあいだを少し空けたいときは、見出しに `margin-bottom` を指定します。

<CodePreview>

```html
<div class="shop-page">
    <h2 class="page-title">おすすめ商品</h2>
    <p class="page-lead">今日のおすすめを3つ紹介します。</p>

    <div class="card-list">
        <div class="card">チョコドーナツ</div>
        <div class="card">カフェラテ</div>
        <div class="card last-card">サンドイッチ</div>
    </div>
</div>
```

```css
.shop-page {
    width: 360px;
    margin: 0 auto;
}

.page-title {
    margin-bottom: 8px;
}

.page-lead {
    margin-bottom: 24px;
}

.card {
    border: 2px solid #7a4b2a;
    padding: 16px;
    margin-bottom: 16px;
    background-color: #fff7ed;
}

.last-card {
    margin-bottom: 0;
}
```

</CodePreview>

よく使う margin の指定は、次の 4 つです。

```css
.example {
    margin-top: 16px;
    margin-right: 16px;
    margin-bottom: 16px;
    margin-left: 16px;
}
```

今回よく使うのは、下側の余白を作る `margin-bottom` です。

上下左右を一度に細かく指定する書き方もありますが、まずは **どの方向に余白を作りたいのか** を考えて、`margin-bottom` のように 1 つずつ指定できるようになりましょう。

</Section>

</Recovery>

<Recovery title="カード同士の間隔が変わらないとき">

カード同士の間隔が変わらないときは、次を確認してください。

- `padding` ではなく `margin-bottom` を書いているか
- `margin-bottom: 16px;` のように、数字のあとに `px` を書いているか
- CSS ファイルを保存しているか
- ブラウザを再読み込みしているか

</Recovery>
