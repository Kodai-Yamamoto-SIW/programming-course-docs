今日は、商品カードを少しずつ作ります。先生と同じように、コードを書きながら見た目が変わるところを確認しましょう。

このレッスンでは、次の3つを覚えます。

- **HTML の `class` と CSS の `.名前` を対応させて、一部分だけを選ぶ**
- ボックスモデルの 4 つの層（content / padding / border / margin）の役割
- `width`・`height`・`border`・`padding` の 4 つのプロパティでカードの見た目を作る

<Section title="一部分だけ色を変えてクラスを覚える" goal="HTML の class と CSS の `.名前` を使って、ページ内の1か所にだけスタイルを当てる方法を覚える">

ここから一緒に作業します。**「180円」だけ色を変えたい**場面から始めます。

### まずはHTMLを書く

クラスが付いていない素のHTMLを用意します。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p>180円</p>
```

```css
/* ここに CSS を書いていきます */
```

</CodePreview>

### `p` をそのまま選ぶと全部に当たる（やってはいけない方法）

タグ名 `p` にスタイルを書くと、**ページの中のすべての `<p>`** に当たります。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p>180円</p>
```

```css
p {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

:::caution[よくある間違い]
`p { ... }` のような **タグ指定** は、ページ内のすべての `<p>` を一括で変える方法です。**一部分だけを変えたいときは使わない**でください。
:::

「おすすめ」も説明文も「180円」も同じ色になりました。値段だけを変えたいときには困ります。

### 値段だけに class を付けて選ぶ（正しい方法）

HTMLで `class="nedan"` を付けた `<p>` にだけ CSS が当たるようにします。CSSでは、さっきの `p { ... }` を `.nedan { ... }` に書き換えます。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p class="nedan">180円</p>
```

```css
.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

**`.nedan` と書いたので、`class="nedan"` が付いた「180円」だけが変わります。**

### class と CSS の対応

<Concept title="class と `.名前` の対応">

- HTMLで `class="名前"` と付けた要素だけが対象になる。
- CSSでは `.名前` と書く（ `.nedan` のように、クラス名の前にドット `1つ`）。

つまり、**HTML側で付けた名前と、CSS側で `.` を付けた名前を、完全に同じにする**ことが部分的にスタイルを当てるコツです。

</Concept>

<Verify>「180円」だけ背景色と文字色が変わっていて、他の段落は素のままである</Verify>

</Section>

### 横幅を決める

`width` は **content（内容を書く場所）の横幅** を決めます。背景色は content と `padding` のところに塗られ、`border` はその外側に線として足されます。

<CodePreview

```html
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    background-color: #fff7ed;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

### 高さを決める

`height` は **content（内容を書く場所）の高さ** を決めます。

```css
.nedan {

    color: #7c2d12;
}
```

</CodePreview>

### ボックスモデルの考え方

<Concept title="CSS のボックスモデル（4つの層）">

HTMLのすべての要素は、**「箱（ボックス）」** の形で表現されます。箱の中身は、内側から外側に向かって次の4つの層に分かれています。

```text
+-----------------------------------+
| margin（外側の余白）                |
|  +-----------------------------+   |
|  | border（枠線）              |   |
|  |  +-----------------------+   |   |
|  |  | padding（内側の余白） |   |   |
|  |  |  +-----------------+ |   |   |
|  |  |  | content         | |   |   |
|  |  |  | （内容・文字）  | |   |   |
|  |  |  +-----------------+ |   |   |
|  |  +-----------------------+   |   |
|  +-----------------------------+   |
+-----------------------------------+
```

内側から外側への順は、**「内容（content）→ 内側の余白（padding）→ 枠線（border）→ 外側の余白（margin）」** です。

:::note[重要]
このレッスンで指定する `width: 300px` と `height: 220px` は、**一番内側の「content（内容）」の大きさ**を決めます。`padding` と `border` はこの大きさには含まれず、あとから別で足されます。
:::

本レッスンでは `padding` と `border` を扱います。`margin` は次の [margin](../margin/index.mdx) で学びます。

</Concept>

<Verify>カードの横幅が `300px`、高さが `220px` に広がっている（背景色の範囲で確認）</Verify>

</Section>

<Section title="枠線と内側の余白を足す" goal="`border` と `padding` を足してカードを商品カードらしく仕上げる">

`padding` と `border` を `.waku` に足していきます。

### 枠線を足す

`.waku` に、次の1行を足します。

```css
border: 2px solid #7a4b2a;
```

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    background-color: #fff7ed;
    border: 2px solid #7a4b2a;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

カードの外側に線が出ます。

`border` は、**要素のまわりに枠線を付けるプロパティ**です。

さっき書いた `border: 2px solid #7a4b2a;` は、枠線の **太さ・種類・色** をまとめて書いたものです。

<Concept title="border の3つの値">

- `2px`：線の太さ
- `solid`：線の種類（実線）
- `#7a4b2a`：線の色

</Concept>

`border` の値は、必ずこの順番でないといけないわけではありません。このレッスンでは読みやすくするために、**太さ → 種類 → 色** の順にそろえて書きます。

:::note[線の種類]
よく使う線の種類には、`solid`（実線）、`dashed`（破線）、`dotted`（点線）、`double`（二重線）があります。

このレッスンでは、まず `solid` だけ使えればOKです。
:::

線の種類を書かない場合、枠線の種類は `none` になります。そのため、`border: 2px #7a4b2a;` のように線の種類だけ抜けると、枠線は表示されません。

### 内側に余白を足す

`.waku` に、次の1行を足します。

```css
padding: 20px;
```

`padding` は、**内容と枠線のあいだの余白**です。

`padding: 20px;` のように数字を1つだけ書くと、**上・右・下・左の4方向すべて**に同じ余白が付きます。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    background-color: #fff7ed;
    border: 2px solid #7a4b2a;
    padding: 20px;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

**文字と枠線のあいだが広がります。**

### 値段にも枠線と余白を足す

同じ考え方で、`.nedan` にも次の2行を足します。

```css
border: 2px solid #c2410c;

```

これで、値段のまわりにも枠線と内側の余白が付きます。

```html
    <p>ふんわり生地にチョコがけ。</p>

</div>
```

```css

    width: 300px;
    height: 220px;
    background-color: #fff7ed;
    border: 2px solid #7a4b2a;

}

    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

値段のまわりにも線と内側の余白が付きます。

<Verify>カードのまわりに枠線が出て、文字と枠線のあいだに余白ができている</Verify>

### AI に質問するときのコツ

:::tip[確認手順を聞く]
AIに「完成コードを全部書く」ように頼むと、丸ごと書き直されてしまい、何が違っていたか分からなくなります。**「どこを確認すればよいか」を手順として聞く**方が、自分で直すべき箇所が見つかります。
:::

次のプロンプトを AI に送ると、段階的な確認手順を教えてもらいやすくなります。

```text
次の HTML と CSS で、class、width、height、border、padding のどれかが思ったように反映されません。
完成コードを全部書くのではなく、どこを確認すればよいかを順番に教えてください。
```

:::note[使い方の流れ]
上のプロンプトのあとに、自分の HTML と CSS を貼り付けて送ると、**「.waku の `.waku` のスペルは正しいか」「border の太さ・種類・色が揃っているか」**のような段階的な確認手順を教えてもらいやすくなります。
