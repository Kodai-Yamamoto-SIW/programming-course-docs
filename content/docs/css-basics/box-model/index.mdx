# カードを作ろう

今日は、商品カードを少しずつ作ります。先生と同じように書きながら、見た目が変わるところを確認しましょう。

---

## 2. 値段だけ色を変える

ここから一緒に作業します。まずは、値段だけ色を変えたい場面を考えます。

### まずはHTMLを書く

最初は、どこにもクラスを付けません。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p>180円</p>
```

```css
/* ここに CSS を書いていきます */
```

</CodePreview>

### pで指定してみる

`p` にスタイルを書くと、すべての `<p>` が変わります。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p>180円</p>
```

```css
p {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

「おすすめ」も説明文も「180円」も同じ色になりました。値段だけを変えたいときには困ります。

次は、今書いた `p { ... }` を消して、値段だけに使う `.nedan { ... }` に書き換えます。

### 値段だけにクラスを付ける

値段の `<p>` だけに `class="nedan"` を付けます。CSSは、さっきの `p { ... }` を消して `.nedan { ... }` に書き換えます。

<CodePreview
>

```html
<p>おすすめ</p>
<h2>チョコドーナツ</h2>
<p>ふんわり生地にチョコがけ。</p>
<p class="nedan">180円</p>
```

```css
.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

`.nedan` と書いたので、`class="nedan"` が付いた「180円」だけが変わります。

### クラスの書き方

HTMLで `class="名前"` と付けると、CSSでは `.名前` でその部分を選べます。

たとえば、HTMLで `class="nedan"` と付けた部分は、CSSで `.nedan` と書いて選びます。

---

## 3. カード全体に名前を付ける

次に、カード全体をまとめて選べるようにします。`<div>` は、いくつかの要素をまとめるためのタグです。

### 全体をdivで囲む

カードにしたい部分を `<div>` で囲みます。

<CodePreview
>

```html
<div>
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

### divにクラスを付ける

この `<div>` に `class="waku"` を付けます。カード全体を選ぶための名前です。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    background-color: #fff7ed;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

背景色が付いた範囲が、`.waku` で選ばれているカード全体です。

---

## 4. 大きさを決める

カード全体に、横幅と高さを指定します。

### 横幅を決める

`width` は横幅を指定します。背景色の横幅が変わるところを確認します。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    background-color: #fff7ed;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

### 高さを決める

`height` は高さを指定します。背景色の付いた四角が、指定した高さになります。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 180px;
    background-color: #fff7ed;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

`width` と `height` は、内容部分の大きさを決めます。

## 5. 枠線と余白を足す

最後に、カード全体に枠線と内側の余白を足します。

### 枠線を足す

`border` は、要素のまわりに枠線をつけます。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 180px;
    background-color: #fff7ed;
    border: 2px solid #333;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

カードの外側に線が出ます。

### 内側に余白を足す

`padding` は、内容と枠線のあいだの余白です。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 180px;
    background-color: #fff7ed;
    border: 2px solid #333;
    padding: 20px;
}

.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

文字と枠線のあいだが広がります。

### 値段にも枠線と余白を足す

同じ考え方で、値段にも `border` と `padding` を足します。

<CodePreview
>

```html
<div class="waku">
    <p>おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p>ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 180px;
    background-color: #fff7ed;
    border: 2px solid #333;
    padding: 20px;
}

.nedan {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

値段のまわりにも線と内側の余白が付きます。

## 8. 完成チェックと困ったとき

まず、できたところを確認しましょう。

* □ `.waku` を使っている
* □ `.waku` に横幅と高さを指定している
* □ `.waku` に枠線と内側の余白がある
* □ `.shirushi` で「おすすめ」だけを指定している
* □ `.nedan` で「180円」だけを指定している
* □ ブラウザで見て、商品カードらしく見える

上から順に確認してください。

* `class="waku"` と `.waku` の名前は同じですか
* `class="nedan"` と `.nedan` の名前は同じですか
* CSSファイルを保存しましたか
* ブラウザを再読み込みしましたか
* `border` に `solid` を書いていますか
* CSSに全角の記号が混ざっていませんか

AIに聞くときは、完成コードではなく確認手順を聞きます。

```text
次の HTML と CSS で、class、border、padding のどれかが思ったように反映されません。
完成コードを全部書くのではなく、どこを確認すればよいかを順番に教えてください。
```

> 上のプロンプトのあとに、自分の HTML と CSS を貼り付けて送ると、段階的な確認手順を教えてもらいやすくなります。
