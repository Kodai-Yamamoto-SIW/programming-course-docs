# ボックスに枠線と内側の余白をつけよう

商品ページやプロフィール欄を作るとき、ただの四角い箱ではなく、周りに線があって文字と線の間にゆとりがある「カード」らしい見た目がよく登場します。前回までに身につけた `class`、`width`、`height` に **枠線（`border`）** と **内側の余白（`padding`）** を足して、見た目をカードに近づけていきましょう。

---

- 文字と枠線のあいだに **余白** がある（`padding: 20px;`）
- 商品名・説明・価格が、**1つのカード** にまとまっている
- ぱっと見て「カードだな」とわかる見た目になっている

- **`height`**：要素の高さを決める

## 3. 今日のポイント

今日の主役は **2つのプロパティ** です。

- **`border`** は、要素のまわりに **枠線** をつけます。枠線があると、ただの四角が「囲われたカード」に変わります。
- **`padding`** は、**内容と枠線のあいだ** の余白です。これがないと、文字が枠線にぴったりくっついて窮屈に見えます。

`border` は **`太さ スタイル 色`** の3つをセットで書く、省略なしの書き方ができます。

- 太さ：`2px` のようにピクセルで指定
- スタイル：`solid`（実線）をまずは覚えておけばOK
- 色：`#333` のようにカラーコードで指定

たとえば `border: 2px solid #333;` と書くと、**2ピクセルの黒い実線** が表示されます。

`padding` は **`padding: 20px;`** のように1つの値で書けば、上下左右ぜんぶに同じだけ余白が入ります。

## 6. うまくいかないとき

よくあるつまずきポイントをまとめました。

1. **`class="card"` と `.card` が対応していない**
   - HTML 側は `class="card"`（`=` のあとに `"` で囲む）
   - CSS 側は `.card`（`.` ドットから始まる）
   - 大文字小文字が違うだけでも反映されません（`card` と `Card` は別物）
2. **CSS ファイルを保存していない / ブラウザで再読み込みしていない**
   - 編集したら保存（Ctrl+S / Cmd+S）を忘れずに
   - ブラウザは `F5` や `Ctrl+R` / `Cmd+R` で再読み込みできます
3. **`border` の `solid` を書き忘れている**
   - `border: 2px #333;` のような書き方だと、枠線が見えないことがあります。**太さ・スタイル・色** の3つを必ず書きましょう
4. **`padding` を書いたのに変化がわかりにくい**
   - 一度 `padding` を消したものと見比べてみてください。**§4-2 の「枠線だけ」の状態** とくらべると、余白の有無がはっきり見えます
5. **全角コロン・全角括弧・日本語の記号が CSS に混ざっている**
   - 見た目は似ていますが、**半角の `:`、`{`、`}`** 以外は CSS が読み取ってくれないことがあります

AI に質問するときのプロンプト例です。**完成コードを答えさせるのではなく、確認の手順を教えてもらう聞き方** にしてみます。

> 次の HTML と CSS で、`border` または `padding` が思ったように反映されません。完成コードを全部書くのではなく、**どこを確認すればよいか** を順番に教えてください。

上のプロンプトのあとに、自分の HTML と CSS を貼り付けて送ると、段階的な確認手順を教えてもらいやすくなります。

## 8. 演習-発展

### 演習-発展1

時間と意欲が余った人は、**基本の演習と同じ形** で、中身のテーマだけ変えて作ってみましょう。`<h2>`・`<p>`・`<p>` の3つを別のテーマの言葉に置き換えるだけです。

たとえば、カフェのメニュー、ゲームの紹介文、ニュースのひとこと欄など、ジャンルは自由です。**`.card` クラス・`width: 300px;`・`height: 180px;`・`border: 2px solid #333;`・`padding: 20px;`** はそのまま使ってください。

余裕があれば、次にも挑戦してみましょう。

- `border` の **太さ**（`2px` → `4px` など）や **色**（`#333` → `tomato` など）を変えて、印象がどう変わるか見る
- `padding` の **値**（`20px` → `10px` や `30px`）を変えて、文字との距離感をくらべる
- もっと余力があれば、`.card` に **`border-radius: 8px;`** を1行だけ足して、角がほんのり丸くなるのを確認する（**任意**）

**解説**:

- **`border-radius`** を加えると、枠線の角が丸くなる
