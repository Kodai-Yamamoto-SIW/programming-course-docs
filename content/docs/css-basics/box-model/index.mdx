# カードを作ろう

今日は、商品ページでよく使うカードを作ります。`class` で部分を選び、`width` / `height` で大きさを決め、`border` / `padding` で枠線と内側の余白をつけます。

---

## 1. 今日作るカード

まずは完成形を見ましょう。

<CodePreview
    previewVisible={true}
    htmlVisible={false}
    cssVisible={false}
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    border: 2px solid #7a4b2a;
    padding: 20px;
    background-color: #fff7ed;
}

.shirushi {
    border: 1px solid #c2410c;
    padding: 4px;
    background-color: #fed7aa;
    color: #7c2d12;
}

.nedan {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

まずは、完成した見た目だけ確認します。作り方はこのあと分けて見ていきます。

このページで作ること:

- カード全体に名前をつける
- 「おすすめ」だけに名前をつける
- 「180円」だけに名前をつける
- 横幅と高さを決める
- 枠線と内側の余白をつける
- 色をそろえて商品カードらしくする

---

## 2. classで部分を選ぶ

カードの中には、複数の `<p>` があります。タグ名セレクタだけで指定すると、すべての `<p>` に同じスタイルが当たります。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
p {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

これだと、「おすすめ」も説明文も「180円」も、すべて同じ色になります。値段だけを目立たせたいときには不便です。

`class` を使うと、特定の部分だけを選べます。HTMLで `class="nedan"` と書いた部分は、CSSで `.nedan` と書いて選びます。

<CodePreview

>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.nedan {
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

`.nedan` と書いたので、「180円」だけにスタイルが当たります。class 名は自分でつけた名前です。

---

## 3. 大きさを決める

`width` は内容部分の横幅、`height` は内容部分の高さを指定します。

`padding` や `border` をあとから足すと、見た目の外側は大きくなります。`width` と `height` が決めるのは、あくまで内容部分の大きさです。

<CodePreview
>

```html
<div class="waku">これは箱です</div>
```

```css
.waku {
    width: 300px;
    height: 180px;
}
```

</CodePreview>

---

## 4. 枠線と余白を足す

`border` は、要素のまわりに枠線をつけます。`border: 2px solid #333;` は、2pxの実線を指定する書き方です。

`padding` は、内容と枠線のあいだの余白です。`padding: 20px;` と書くと、上下左右に20pxの余白が入ります。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    border: 2px solid #7a4b2a;
    padding: 20px;
    background-color: #fff7ed;
}

.shirushi {
    border: 1px solid #c2410c;
    padding: 4px;
    background-color: #fed7aa;
    color: #7c2d12;
}

.nedan {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

## 5. 一緒に作る

4つの段階で、カードが変わる様子を確認します。

### ステップ1：classを付ける

まずはHTMLに class を付けます。まだCSSを書いていないので、見た目は変わりません。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
/* ここに CSS を書いていきます */
```

</CodePreview>

### ステップ2：大きさを決める

`.waku` に `width` と `height` を書きます。カードの内容部分が、横300px・縦220pxになります。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
}
```

</CodePreview>

### ステップ3：枠線と余白を足す

`.waku` に `border` と `padding` を足します。これで、カード全体がひとつの箱に見えます。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    border: 2px solid #333;
    padding: 20px;
}
```

</CodePreview>

### ステップ4：価格だけ目立たせる

ステップ3から増えたのは `.nedan` だけです。`class="nedan"` の部分だけを選べるので、値段だけを目立たせられます。

<CodePreview
>

```html
<div class="waku">
    <p class="shirushi">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="setsumei">ふんわり生地にチョコがけ。</p>
    <p class="nedan">180円</p>
</div>
```

```css
.waku {
    width: 300px;
    height: 220px;
    border: 2px solid #333;
    padding: 20px;
}

.nedan {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

## 7. 困ったとき

上から順に確認してください。

- `class="waku"` と `.waku` の名前は同じですか
- `class="nedan"` と `.nedan` の名前は同じですか
- CSSファイルを保存しましたか
- ブラウザを再読み込みしましたか
- `border` に `solid` を書いていますか
- CSSに全角の記号が混ざっていませんか

AIに聞くときは、完成コードではなく確認手順を聞きます。

```text
次の HTML と CSS で、class、border、padding のどれかが思ったように反映されません。
完成コードを全部書くのではなく、どこを確認すればよいかを順番に教えてください。
```

上のプロンプトのあとに、自分の HTML と CSS を貼り付けて送ると、段階的な確認手順を教えてもらいやすくなります。
