# カードの形を作ろう：class・大きさ・枠線・内側余白

ウェブページでは、商品紹介やプロフィール表示など、「四角い枠で囲まれて、中身に余白がある見た目」がよく登場します。これが **カード** と呼ばれる形です。今日は `class` で「部分」に名前をつけ、`width` と `height` で形を決め、`border` と `padding` で枠線と余白をつけて、商品ページのカードを作っていきます。

---

## 1. 今日作るもの

まずは完成形を見ましょう。最終的に、次のようなカードが表示されるのが目標です。

<CodePreview
    previewVisible={true}
    htmlVisible={false}
    cssVisible={false}
>

```html
<div class="card">
    <p class="label">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="description">ふんわり生地にチョコがけ。</p>
    <p class="price">180円</p>
</div>
```

```css
.card {
    width: 300px;
    height: 220px;
    border: 2px solid #7a4b2a;
    padding: 20px;
    background-color: #fff7ed;
}

.label {
    border: 1px solid #c2410c;
    padding: 4px;
    background-color: #fed7aa;
    color: #7c2d12;
}

.price {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

このカードには、次の5つの特徴があります。

- `.card` がカードの **全体** を選んでいる
- `.label` が「おすすめ」の **ラベルだけ** を選んでいる
- `.price` が「180円」の **価格だけ** を選んでいる
- `width` と `height` でカードの **内容部分の幅・高さ** を決めている
- `border` と `padding` で枠線と余白をつけ、**カードらしい見た目** を作っている
- 枠線と背景色を組み合わせると、商品カードらしく見える

この5つを順に作っていきます。

---

## 2. class を使う理由

カードの中には、複数の `<p>` が並んでいます。「おすすめ」「ふんわり生地にチョコがけ。」「180円」、ぜんぶ `<p>` です。タグ名セレクタだけで指定してしまうと、**すべての `<p>` に同じスタイル** がかかってしまいます。

たとえば、次のように書くとどうなるか見てください。

<CodePreview
>

```html
<div class="card">
    <p class="label">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="description">ふんわり生地にチョコがけ。</p>
    <p class="price">180円</p>
</div>
```

```css
p {
    border: 1px solid #333;
    padding: 4px;
}
```

</CodePreview>

タグ名セレクタ `p` は、**クラスに関係なく** すべての `<p>` を選んでしまいます。ラベルの「おすすめ」も、説明の「ふんわり生地にチョコがけ。」も、価格の「180円」も、ぜんぶ同じ枠線で囲まれてしまいました。これでは価格だけ目立たせることができません。

ここで `class` の出番です。`class` は **要素に好きな名前をつけて、その名前だけを選べるようにする** 仕組みです。HTML で `class="price"` と書いた要素には、CSS 側で `.price` と書けば **その要素だけ** に正確にマッチします。

<CodePreview
>

```html
<div class="card">
    <p class="label">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="description">ふんわり生地にチョコがけ。</p>
    <p class="price">180円</p>
</div>
```

```css
.price {
    border: 2px solid #333;
    padding: 8px;
}
```

</CodePreview>

今回は「180円」だけに枠線と余白がつきました。`class` を使うと、**どの「部分」にスタイルを当てたいか** を CSS 側に明確に伝えられます。

最初の完成形カードで用意していた `.card`（カード全体）・`.label`（ラベル）・`.price`（価格）の **3つの class** は、見た目が違う **別の部分** なので別の名前にしていました。`.description` のように HTML に名前を残しつつ CSS を書かない、という選択も「class で対象を分ける」考え方のひとつです。

---

## 3. width / height でカードの形を作る

カードには、**決まった大きさ** が必要です。商品名や説明文が画面いっぱいに広がってしまうと、見出しなのか本文なのか区別がつかなくなります。`width` と `height` を使うと、要素の **内容部分の幅・高さ** を指定できます。

- `width` は **内容部分の幅**
- `height` は **内容部分の高さ**

「内容部分」とは、文字や画像などの中身が入る領域のことです。`padding` や `border` をあとから足すと、見た目はずいぶん広くなりますが、`width` と `height` が決めているのはあくまで **内容部分** の大きさです。このあと出てくる `padding` や `border` とは分けて覚えておいてください。

`width` も `height` も指定しないと、要素は **親の幅いっぱいに広がろうとしたり、中身の高さに合わせて縮んだり** します。カードのように「同じ形の箱をくり返し並べたい」ときは、`width` と `height` を **両方とも指定** して形を固定するのが基本です。

次の例では、まだ `border` も `padding` も入れていませんが、`width` と `height` を指定するだけで固定サイズの四角になります。

<CodePreview
>

```html
<div class="card">これは箱です</div>
```

```css
.card {
    width: 300px;
    height: 180px;
}
```

</CodePreview>

ここまでではまだ枠線も余白もありませんが、**形はもう決まっている** ことが確認できます。次に `border` と `padding` を加えて、見た目を「カード」にしていきましょう。

---

## 4. border / padding でカードらしくする

`width` と `height` だけでは輪郭が見えないため、どこからどこまでがカードなのか目で追いにくい状態です。ここに **枠線** と **内側の余白** を足すと、はじめて「カードらしい見た目」になります。

- **`border`** は、要素のまわりに **枠線** をつけます。これがあると、ただの四角が「囲われたカード」に変わります。
- **`padding`** は、**内容と枠線のあいだ** の余白です。これがないと、文字が枠線にぴったりくっついて窮屈に見えます。

`border` は **太さ スタイル 色** の3つをセットで書きます。

- **太さ**:`2px` のようにピクセルで指定します。
- **スタイル**:`solid`（実線）をまずは覚えておけば OK です。
- **色**:`#333` のようにカラーコードで指定します。

たとえば `border: 2px solid #333;` と書くと、**2 ピクセルの黒い実線** が表示されます。3つの値は **この順番** で書く、と覚えておいてください。今日の授業では `solid` だけ使います。

`padding` は **1つの値** で書けば、上下左右ぜんぶに同じだけ余白が入ります。`padding: 20px;` と書けば、上下左右すべてに 20 ピクセルの余白が入ります。`padding` の値が **大きいほど** 文字と枠線のあいだが広くなります。

完成形カードでは `.card` だけでなく、`.label` や `.price` にも `border` と `padding` をつけて、**カードの中の小さな部分にも枠線と余白がある** 見せ方をしていました。

- `.card` はカード全体の枠線
- `.label` は小さなラベルの枠線
- `.price` は価格をしっかり囲む枠線

`border` と `padding` は **カード全体にも、部品ひとつひとつにも使える** 道具です。`.card` に書くか、`.label`・`.price` に書くかは **どこを囲みたいか** で決まります。

次のプレビューは、今日の完成形そのものです。`.card`・`.label`・`.price` のそれぞれが `border` と `padding` を持っていることを確認してみましょう。

<CodePreview

```html

    <p class="label">おすすめ</p>
    <h2>チョコドーナツ</h2>
    <p class="description">ふんわり生地にチョコがけ。</p>
    <p class="price">180円</p>
</div>
```

```css

    width: 300px;
    height: 220px;
    border: 2px solid #7a4b2a;
    padding: 20px;
    background-color: #fff7ed;
}

.label {
    border: 1px solid #c2410c;
    padding: 4px;

    color: #7c2d12;
}

.price {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

## 7. うまくいかないとき

よくあるつまずきポイントをまとめました。困ったときは上から順に確認してみてください。

- **`class="card"` と `.card` が対応していない**
    - HTML 側は `class="card"`（`=` のあとに `"` で囲む）
    - CSS 側は `.card`（`.` ドットから始まる）
    - 大文字小文字が違うだけでも反映されません（`card` と `Card` は別物）
- **`class="price"` と `.price` が対応していない**
    - 同じ `class` 名でも、HTML 側と CSS 側で **一字一句同じ** である必要があります
- **CSS ファイルを保存していない / ブラウザを再読み込みしていない**
    - 編集したら保存（Ctrl+S / Cmd+S）を忘れずに
    - ブラウザは `F5` や `Ctrl+R` / `Cmd+R` で再読み込みできます
- **`border` の `solid` を書き忘れている**
    - `border: 2px #333;` のような書き方だと、枠線が見えないことがあります。**太さ・スタイル・色** の3つを必ず書きましょう
- **`padding` の変化が分かりにくい**
    - `padding` を書いたあと、**一度 `padding` を消したものと見比べて** みてください。枠線とのあいだの余白の有無がはっきり見えます
- **全角コロン・全角括弧・日本語の記号が CSS に混ざっている**
    - 見た目は似ていますが、**半角の `:`、`{`、`}`** 以外は CSS が読み取ってくれないことがあります

AI に質問するときのプロンプト例です。完成コードを答えさせるのではなく、**どこを確認すればよいか** を聞く書き方にしてみます。

```text
次の HTML と CSS で、class、border、padding のどれかが思ったように反映されません。
完成コードを全部書くのではなく、どこを確認すればよいかを順番に教えてください。
```

上のプロンプトのあとに、自分の HTML と CSS を貼り付けて送ると、段階的な確認手順を教えてもらいやすくなります。

**HTML の骨組み**:

```html
<div class="card">
    <p class="label">ジャンル</p>
    <h2>タイトル</h2>
    <p class="description">説明文</p>
    <p class="price">補足情報</p>
</div>
```

**やってよいこと**:

- 選んだテーマに合わせて **テキスト** を書き換える
- `.label` や `.price` の **枠線の太さ** や **色** を変えて印象をくらべる
- `.card` の `padding` の **値** を変えて、文字との距離感をくらべる
- **余裕があれば**、`.card` に `border-radius: 8px;` を1行だけ足して、角がほんのり丸くなるのを確認してみましょう（任意）

<Solution>

カフェメニューを例にした例です。テーマに合わせてテキストや値の調整をしてみましょう。

<CodePreview
>

```html
<div class="card">
    <p class="label">おすすめ</p>
    <h2>カフェラテ</h2>
    <p class="description">ほっとひと息、ミルクたっぷり。</p>
    <p class="price">420円</p>
</div>
```

```css
.card {
    width: 300px;
    height: 220px;
    border: 2px solid #7a4b2a;
    padding: 20px;
    background-color: #fff7ed;
    border-radius: 8px;
}

.label {
    border: 1px solid #c2410c;
    padding: 4px;
    background-color: #fed7aa;
    color: #7c2d12;
}

.price {
    border: 2px solid #c2410c;
    padding: 8px;
    background-color: #ffedd5;
    color: #7c2d12;
}
```

</CodePreview>

**解説**:

- HTML の中身はテーマに合わせて自由に書き換えて OK
- `.card` の `border-radius` を加えると、枠線の **角がほんのり丸くなる**
- `border` の太さや色、`padding` の値を変えることで、同じカード構造でも **印象が変わる**

</Solution>

今日の授業では、`class` で **どの「部分」** に名前を付けるか、`width` と `height` で **内容部分の大きさ** をどう決めるか、`border` と `padding` で **枠線と内側余白** をどうつけるか、を一通り体験しました。この組み合わせは、商品カード以外の「枠で囲まれたパーツ」でも繰り返し使う基本セットです。
