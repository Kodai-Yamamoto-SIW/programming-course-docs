# デザインカンプからのマークアップ

## この演習について

ここからは、**完成見本（デザインカンプ）を見て、同じ構造になるHTMLを書く** 演習です。

今回はCSSは書きません。HTMLの構造づくりだけに集中しましょう。  
CSSは次の単元で学びます。自分が書いたHTMLは色や枠のないブラウザそのままの見た目になりますが、それで正解です。

:::note

**デザインカンプ** とは、Webサイトを作るときにデザイナーが先に作る「このページはこういう見た目になります」という完成見本のことです。プログラマーはカンプを見ながらHTMLとCSSを書いてサイトを再現していきます。

:::

## カンプを読む4ステップ

カンプを上から下まで眺めて「とりあえず書く」と、入れ子の階層がバラバラになって迷子になります。  
次の順番で **構造を取り出してから** マークアップしましょう。

1. **大枠を分ける**  
   ページ全体を `header` / `main` / `footer` の3つに分ける
2. **`main` の中をテーマで分ける**  
   テーマごとに `section` で囲む。多くの場合、1つの `section` は「**見出し1つ + その下の中身**」のかたまりになる。
3. **見出しの階層を決める**  
   ページ全体のタイトルは `h1`。各 `section` の見出しは入れ子の深さで決まる（`main` 直下なら `h2`、さらに `section` を入れ子にしたらその中は `h3`）。
4. **中身を要素に割り当てる**  
   文章は `p`、項目を並べる場所は `ul` / `li`、画像は `img`、リンクは `a`

「見たまま書く」のではなく、「構造を決めてから書く」のがコツです。

**なぜこの構造になるのか:**
