**なぜこの構造になるのか:**

- **ヘッダー**: サイト名とページ移動用のリンクをまとめる、ページ上部の共通的な領域なので `header` にします。
- **ナビゲーション**: リンクのまとまりなので、`header` の中の `nav` にします。
- **大きな紹介エリア**: このページで一番見せたいメインコピーなので、`main` の最初の `section` として扱います。
- **カード風の2項目**: 見た目はカードですが、意味としては「過ごし方」の小さなテーマなので、内側の `section` にします。
