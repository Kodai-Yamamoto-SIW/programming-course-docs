## この演習について

今回は、**色・余白・角丸・影がついたデザインカンプから、HTMLの構造だけを読み取る** 演習です。

CSSは書きません。CSSファイル、`<style>`、`style=""`、装飾のための `class` / `id` は使わないでください。  
カードの枠、色のついた帯、影、背景色は **CSSで作られる見た目** です。HTMLでは「何の情報が、どのまとまりに入っているか」を表します。

:::note

装飾のあるカンプを見ると、色のついた箱をそのままHTMLタグにしたくなります。けれど、HTMLに「カード」「青い背景」「影」というタグはありません。**見た目の箱は、見出し・段落・リストなどの中身のまとまりを見つけるための手がかり** として読みましょう。

:::

## 装飾から構造を読む3ステップ

装飾はHTMLに書くものではありません。  
ただし、構造を読むためのヒントにはなります。

1. **大きな色のかたまりを見る**  
   ページ全体の上部なら `header`、本文なら `main`、最後の補足なら `footer` になりやすい。
2. **同じ見た目のカードを探す**  
   同じ形のカードが並んでいたら、同じ種類の情報がくり返されている。
3. **装飾と意味を分ける**  
   色、角丸、影、余白はCSS。見出し、文章、項目リスト、リンク、重要な言葉などの、文章や、意味付けはHTML。

今回は、装飾のあるカンプから、HTMLの構造を読み取る練習をしてみましょう。
