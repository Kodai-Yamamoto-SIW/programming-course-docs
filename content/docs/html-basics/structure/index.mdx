## HTMLの基本構造

HTML文書の基本形は共通基礎で確認済みです。ここでは、演習でよく読む要素だけを短く確認します。

### `<!DOCTYPE html>`

- HTML文書であることを宣言
- 文書の先頭に必ず書く

### `<html>`要素

- HTML文書のルート要素
- `lang`属性で言語を指定
    - 日本語の場合は`ja`
    - 例：`<html lang="ja">`

### `<head>`要素

- 文書のメタ情報を記述
- 通常含まれるもの：
    - `<title>`: ページのタイトル
    - `<meta>`: 文字コードなどの情報
    - `<style>`: CSS
    - `<link>`: 外部ファイルのリンク
    - `<script>`: JavaScript

### `<body>`要素

- ページに表示される内容を記述
- 通常含まれるもの：
    - 文章
    - 見出し（`<h1>`～`<h6>`）
    - 段落（`<p>`）
    - リスト（`<ul>`, `<ol>`, `<li>`）
    - リンク（`<a>`）
    - 画像（`<img>`）
    - その他のコンテンツ

## 要素と属性

共通基礎では、要素はタグで囲まれたまとまり、属性は開始タグに書く追加情報として確認しました。

演習では、要素名と属性を見分けます。

```html
<要素名 属性名="属性値" 属性名="属性値">
```

- 1つの要素に複数の属性を指定することができます
- 属性と属性の間は半角スペースで区切ります

### 確認例

```html
<html lang="ja">
    ...
</html>
```

- 要素：`<html lang="ja">`から`</html>`まで
- 属性：`lang="ja"`

## 入れ子構造

共通基礎では、要素の中に別の要素を入れることを **入れ子** と確認しました。

このページでは、タグの閉じ方が崩れていないかを見つける練習をします。

### HTMLのインデント

入れ子構造を作るときに欠かせないのが「インデント（字下げ）」です。
親要素の中に子要素を入れるとき、**子要素は親要素よりも1段（スペース4つ分）深くインデント**します。

#### 良い例（インデントが揃っている）

```html
<section>
    <h2>プロフィール</h2>
    <ul>
        <li>名前：山田太郎</li>
        <li>趣味：読書</li>
    </ul>
</section>
```

#### 悪い例（インデントがぐちゃぐちゃ）

{/*prettier-ignore*/}

```html
<section>
<h2>プロフィール</h2>
    <ul>
<li>名前：山田太郎</li>
        <li>趣味：読書</li>
    </ul>
</section>
```

悪い例では、どこまでが `<ul>` の中なのか、どこが `<section>` の終わりなのかがひと目で分かりません。構造が複雑になるほど、インデントの乱れは「タグの閉じ忘れ」などのエラーを引き起こす原因になります。
VSCodeでは、コードを選択して `Alt + Shift + F` (Windows) または `Option + Shift + F` (Mac) を押すことで自動的にインデントを整えることができますが、まずは自分で「入れ子になったら下げる」意識を持ちましょう。

### 正しい入れ子の例

```html
<ul>
    <li>項目1</li>
    <li>項目2</li>
</ul>
```

### 間違った入れ子の例

{/*prettier-ignore*/}

```html
<ul>
    <li>項目1
</ul>
    </li>
```

- タグの順序が正しくない
- 開始タグと終了タグの対応が取れていない

### 確認すること

1. 開始タグと終了タグの順序を正しくする
2. 親要素の開始タグ → 子要素の開始タグ → 子要素の終了タグ → 親要素の終了タグ
3. タグの対応関係を明確にする

## コメント

コメントの基本は共通基礎で確認済みです。ここでは、HTMLの中に区切りコメントを追加する練習をします。

```html
<!-- コメントの内容 -->
```

### コメントの例

```html
<!-- これは見出しです -->
<h1>タイトル</h1>

<!--
    複数行のコメントも
    このように書けます
-->
<p>本文</p>

<!-- 一時的に無効化
<img src="image.jpg" alt="画像">
-->
```

### 演習3

<Exercise>

1. 以下のHTMLに、セクションの区切りを示すコメントを追加してください：


```html

<p>〇〇大学 情報学部</p>

<h2>職歴</h2>
<p>〇〇株式会社 システム開発部</p>
```

```html

<p>名前：山田太郎</p>

<p>〇〇大学 情報学部</p>
```

</Solution>
